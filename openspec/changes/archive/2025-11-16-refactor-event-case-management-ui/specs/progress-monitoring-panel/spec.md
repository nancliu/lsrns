# 展开/折叠式进度监控面板 (Progress Monitoring Panel)

监测面板应支持展开/折叠两种状态，根据展开/折叠状态调整数据刷新频率，简化显示内容（移除ETA），提供筛选排序和快捷分析导航功能。

**Affected Files**:
- `frontend/scenarios/case-simulation-center.html`
- `frontend/scenarios/css/event-scenario-comparison.css`

---

## ADDED Requirements

### Requirement: 展开/折叠式面板容器 - 支持两种状态切换，默认折叠
The system SHALL implement this requirement.
监测面板应支持展开/折叠两种状态，通过单一的展开/收起按钮控制，默认状态为折叠。

#### Scenario: 用户首次进入页面，面板默认折叠

```
Given: 用户打开 case-simulation-center.html
When: 页面加载完成
Then: 进度监控面板显示为折叠状态（最小化）
And: 显示折叠状态内容：总体进度条 + 关键统计卡片（总/完成/运行/失败）
And: 有一个明显的"展开"按钮/箭头
And: 与案例列表在同一页面显示
```

#### Scenario: 用户点击展开按钮，面板平滑展开

```
Given: 进度监控面板处于折叠状态
When: 用户点击"展开"按钮或切换按钮
Then: 面板平滑展开（CSS transition 动画，约300ms）
And: 显示详细表格、筛选控件、排序选项
And: "展开"按钮变为"折叠"按钮（图标反向）
And: 页面布局自动调整，无抖动/闪烁
And: 数据刷新频率自动调整为 5-10 秒一次
```

#### Scenario: 用户点击折叠按钮，面板平滑折叠

```
Given: 进度监控面板处于展开状态
When: 用户点击"折叠"按钮
Then: 面板平滑折叠（CSS transition 动画，约300ms）
And: 仅显示关键信息（进度条 + 统计卡片）
And: 数据刷新频率自动调整为 30 秒一次（降低服务器压力）
And: 节省屏幕空间，便于查看案例列表
```

### Requirement: 折叠状态显示内容 - 简洁显示进度关键信息
The system SHALL implement this requirement.

折叠状态下应简洁显示进度的关键信息，便于快速了解批次进度而不占用过多空间。

#### Scenario: 折叠状态默认显示

```
Given: 监测面板处于折叠状态
Then: 显示以下内容：
  - 标题：例如 "📊 实时监测" 或 "进度监控"
  - 总体进度条：显示 X% 完成（0-100%，实时更新，宽度 100%）
  - 关键统计卡片（4个）：
    * 总计：N 个仿真
    * 已完成：N 个 (绿色背景)
    * 运行中：N 个 (蓝色背景)
    * 失败：N 个 (红色背景)
  - 展开按钮/箭头：用户可点击查看详细内容
```

#### Scenario: 折叠状态下进度条实时更新

```
Given: 批次正在运行，有多个仿真进行中
When: 后端返回最新进度数据（每30秒）
Then: 进度条平滑更新（宽度变化，无抖动）
And: 进度百分比正确计算（基于状态统计）
And: 进度条颜色始终为绿色表示正常
```

### Requirement: 展开状态显示内容 - 详细表格和筛选排序
The system SHALL implement this requirement.

展开状态下应提供详细的监控信息，支持筛选和排序，便于管理和查看具体的仿真进度。

#### Scenario: 展开状态显示完整信息

```
Given: 监测面板处于展开状态
Then: 显示以下内容（在折叠内容基础上添加）：
  - 统计卡片（4个）：与折叠状态相同
  - 总体进度条：与折叠状态相同
  - 筛选和搜索控件：
    * 状态筛选下拉菜单（全部/已创建/仿真中/已完成/失败）
    * 搜索框：按仿真ID或案例ID搜索
  - 详细表格：显示每个仿真的详细信息
    * 仿真ID
    * 案例名称/ID
    * 控制策略（如有）
    * 状态（带颜色标签）
    * 进度条（百分比）
    * 运行时间
    * 操作列："查看分析" 按钮 (仿真完成时启用)
```

#### Scenario: 表格排序功能

```
Given: 展开状态下显示详细表格
When: 用户点击表头（仿真ID、案例、状态、进度、时间等列）
Then: 表格按该列排序（升序/降序切换）
And: 排序箭头（↑↓）显示在当前排序列
And: 表格数据重新排列，动画平滑无抖动
```

#### Scenario: 表格筛选功能

```
Given: 展开状态下显示详细表格
When: 用户从状态筛选下拉菜单选择条件（例如 "仿真中"）
Then: 表格仅显示符合条件的行
And: 统计卡片保持不变（始终显示全部统计）
And: 支持多条件筛选（Ctrl/Cmd 多选）
And: 搜索框和筛选同时生效
```

### Requirement: 动态数据刷新机制 - 根据面板状态调整刷新频率
The system SHALL implement this requirement.

根据面板展开/折叠状态动态调整数据刷新频率，优化性能和服务器压力。

#### Scenario: 展开状态高频刷新

```
Given: 监测面板处于展开状态
When: 用户展开面板或面板已展开
Then: 每 5-10 秒自动刷新一次数据
And: 调用 API 获取最新的仿真进度
And: 显示"上次更新：X 秒前"时间戳（可选）
And: 刷新过程中不冻结用户交互
```

#### Scenario: 折叠状态低频刷新

```
Given: 监测面板处于折叠状态
When: 用户折叠面板或页面加载时面板折叠
Then: 每 30 秒自动刷新一次数据（降低服务器压力）
And: 进度条和统计卡片定期更新
And: 用户可继续查看和操作案例列表，不受频繁刷新影响
```

#### Scenario: 批次完成停止刷新

```
Given: 所有仿真均已完成或失败
When: 数据更新时检测到所有仿真状态为完成/失败
Then: 停止自动刷新
And: 显示"监测完成"或类似提示
And: 提供"返回案例列表"或"新建批次"选项
```

### Requirement: 查看分析快捷导航 - 从监控面板直接跳转到分析
The system SHALL implement this requirement.

在监控面板详细表格中，每行仿真都应提供快捷跳转到分析页面的按钮。

#### Scenario: 仿真完成时显示查看分析按钮

```
Given: 展开状态下显示详细表格，某仿真已完成
When: 用户看到表格最后一列的"查看分析"按钮
Then: 按钮处于启用状态（可点击，颜色清晰）
And: 鼠标悬停时显示提示："查看该仿真的分析结果"
```

#### Scenario: 点击查看分析按钮导航

```
Given: 某仿真已完成，"查看分析"按钮启用
When: 用户点击该行的"查看分析"按钮
Then: 跳转到 analysis_viewer.html?case_id={case_id}&simulation_id={sim_id}
And: analysis_viewer 根据 URL 参数加载对应的分析结果
And: 分析页面显示"返回案例管理"按钮，支持返回本页面
```

#### Scenario: 仿真进行中时禁用按钮

```
Given: 某仿真状态为"仿真中"或"已创建"
When: 用户看到表格中的"查看分析"按钮
Then: 按钮应禁用（灰显，不可点击）
And: 鼠标悬停时显示提示："请等待仿真完成后查看分析"
```

## MODIFIED Requirements

### Requirement: 更新现有统计卡片样式 - 优化响应式布局
The system SHALL implement this requirement.

现有统计卡片在折叠/展开状态下应保持一致，但需要优化样式以适应不同屏幕宽度。

#### Scenario: 统计卡片响应式布局

```
Given: 用户在不同屏幕宽度查看进度监控
When: 宽度 > 1200px (桌面)
Then: 显示 4 个统计卡片横排（网格布局）
When: 宽度 768px - 1200px (平板)
Then: 显示 2x2 网格或 4 列（根据实际宽度）
When: 宽度 < 768px (移动)
Then: 显示单列或 2 列排列
And: 所有卡片可见，无需水平滚动
```

---

## 验收标准

- [ ] 面板默认折叠，显示关键信息
- [ ] 展开/折叠按钮可点击，动画流畅（无抖动，约300ms）
- [ ] 根据面板状态自动调整刷新频率（展开5-10s，折叠30s）
- [ ] 详细表格支持筛选、排序、搜索
- [ ] "查看分析"按钮在仿真完成时启用，点击正确跳转
- [ ] 进度条和统计卡片实时更新
- [ ] 浏览器控制台无 JavaScript 错误或警告
- [ ] 响应式设计在 768px 和 1200px 断点处正确切换
- [ ] 在移动设备上所有内容可见（无截断）
