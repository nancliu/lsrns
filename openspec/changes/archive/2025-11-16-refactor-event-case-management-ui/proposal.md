# 事件场景案例管理UI重构提案

## 概述

重构事件场景案例管理页面（case-simulation-center.html）和分析页面（analysis_viewer.html），提升进度监控功能的可用性和分析页面的功能完整性。

核心改进：
1. **展开/折叠式进度监控面板** - 集成进度监控和案例列表，提高整合度
2. **简化进度监控信息** - 显示总体进度条和详细表格，移除复杂的ETA计算
3. **批次对比分析** - 在analysis_viewer.html中支持多案例/多仿真的对比分析

**Status**: 🔄 进行中（部分已实现，需完善）
**Phase**: Phase 2 - 进度监控优化与分析页面扩展

## 问题陈述

### 当前问题（Phase 1已解决）
1. ✅ 工作流割裂 - 已通过单页面设计解决
2. ✅ UI混乱 - 已移除tab设计
3. ✅ 缺乏批量操作 - 已实现多选和批量启动
4. ⏳ 监测功能不完整 - **本阶段继续完善**

### 待完善问题（Phase 2）
1. **进度监控整合度不足** - 当前监测面板在底部，与案例列表分离；用户无法在同一视图中高效查看进度和管理案例
2. **监测信息过度复杂** - 显示了ETA等计算字段，实际上只需要总体进度和详细表格
3. **分析页面缺乏批次对比** - analysis_viewer.html仅支持单个案例分析，无法对比多个仿真结果
4. **分析页面响应式设计不足** - 在不同屏幕宽度下表现不佳

## 解决方案

### 核心改进

#### Phase 1（已完成）✅
1. **单页面统一设计** - 移除3个tab，采用面板切换（案例列表 ↔ 监测面板）
2. **多选和批量操作** - 支持全选、单选、批量启动
3. **实时监测面板** - 显示仿真统计、进度、详情表格

#### Phase 2（本阶段）🔄

**2.1 进度监控面板优化（case-simulation-center.html）**
- 将监测面板改为**展开/折叠式**设计，默认折叠
- 在案例列表上方或右侧显示可收缩的监控区域
- 简化显示内容：**总体进度条** + **关键统计**（总数/完成/运行/失败）
- 移除复杂的ETA计算字段
- 在展开状态下显示详细表格（仿真ID/案例/状态/进度）

**2.2 分析页面扩展（analysis_viewer.html）**
- 添加**批次对比标签页** - 支持同时查看多个案例的分析结果
- 改进**响应式布局** - 优化在不同屏幕宽度下的表现
- 增强**数据可视化** - 改进图表和表格的设计
- 添加**案例/仿真选择器** - 支持快速切换不同案例的分析结果

### 实现范围
- ✅ Phase 1 完成：case-simulation-center.html（案例列表、多选、批量启动）
- 🔄 Phase 2 进行中：
  - case-simulation-center.html - 展开/折叠式进度监控
  - analysis_viewer.html - 批次对比分析和响应式优化
  - 后端 API 无需改动（复用现有接口）

## 关键特性

### Phase 1 特性（已实现）✅

#### 1. 单页面管理界面
- 案例列表展示（带多选）
- 批量操作控制区
- 实时监测面板（初始隐藏）

#### 2. 多选功能
- 全选/反选复选框
- 选中行高亮显示
- 选中统计计数

#### 3. 批量启动
- 确认模态框（显示选中案例清单）
- 调用 `/simulation/batch-start` API
- 自动显示监测面板

#### 4. 基础实时监测（Phase 1版本）
- 统计卡片（总计/已完成/运行中/失败）
- 进度条（0-100%）
- 仿真详情表格（仿真ID/案例ID/状态/进度）
- 每10秒自动刷新

### Phase 2 特性（本阶段）🔄

#### 5. 展开/折叠式进度监控（case-simulation-center.html）
- **折叠状态**（默认）
  - 显示总体进度条
  - 显示关键统计：总数/完成数/运行中/失败
  - 点击可展开详细信息
- **展开状态**
  - 显示完整的仿真详情表格
  - 显示总体进度条和统计卡片
  - 支持按状态筛选、排序
  - 点击可折叠

#### 6. 改进的数据刷新机制
- 根据监测面板展开/折叠状态调整刷新频率
- 展开时：5-10秒刷新一次
- 折叠时：30秒刷新一次（降低服务器压力）

#### 7. 分析集成（case-simulation-center.html）
- "查看分析结果" 按钮（在监测面板表格每行）
- 跳转到 `analysis_viewer.html?case_id={case_id}&simulation_id={sim_id}`
- 分析页面可根据URL参数回跳返回案例列表

#### 8. 批次对比分析（analysis_viewer.html）
- 新增**对比分析标签页**
  - 支持选择多个案例/仿真进行对比
  - 并排对比关键指标
  - 支持差异高亮显示
- 改进现有标签页的响应式设计
- 添加**案例选择器** - 快速切换不同案例

#### 9. 响应式布局优化（analysis_viewer.html）
- 优化移动设备（<768px）：单列布局，表格可横向滚动
- 优化平板设备（768px-1200px）：双列布局
- 优化桌面设备（>1200px）：多列布局，充分利用屏幕空间

## 技术债务和限制

### Phase 1 已知限制
1. **batch-status API** - 后端未实现，前端自动回退到通用模式（可接受）
2. **单event批次** - 当前批量启动只支持同一事件的case（需求合理）

### Phase 2 需要解决的技术问题
1. **响应式CSS** - 需要优化多个@media查询断点
2. **数据加载性能** - 对比分析可能涉及大量数据，需要分页或虚拟滚动
3. **URL参数同步** - analysis_viewer需要可靠的回跳机制
