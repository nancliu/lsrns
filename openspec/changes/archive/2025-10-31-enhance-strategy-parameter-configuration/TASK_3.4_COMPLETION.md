## 任务目标

实现策略描述自动生成功能，在用户进入 Step 3（配置参数页面）时，自动根据以下信息生成详细的策略描述：

## 实现概述

### 1. 核心类：`StrategyDescriptionGenerator`

**位置**: `frontend/control/templates.html:2206-2350`

**功能**:
- 根据策略类型生成相应格式的详细描述
- 提取路段信息（路线代码、桩号范围）
- 检测时间段模式（早高峰、晚高峰、早晚高峰、全天）
- 生成多段式描述（基本信息 + 策略目标 + 适用场景 + 安全保障等）

**类方法**:

```javascript
class StrategyDescriptionGenerator {
    // 主入口：根据模板类型分发到具体生成器
    static generate(template, edges, parameters)

    // VSS策略描述生成器
    static generateVSSDescription(template, edges, parameters)
    // 格式：基本信息 + 策略目标 + 适用场景

    // DHS策略描述生成器
    static generateDHSDescription(template, edges, parameters)
    // 格式：基本信息 + 策略目标 + 安全保障 + 适用场景

    // TEC策略描述生成器
    static generateTECDescription(template, edges, parameters)
    // 格式：基本信息 + 控制参数 + 策略目标 + 适用场景
}
```

### 2. 自动填充函数：`autoPopulateStrategyDescription()`

**位置**: `frontend/control/templates.html:2356-2401`

**功能**:

## 生成规则详解

### VSS (可变限速) 策略

**格式**: 多段式描述

**段落结构**:
1. **基本信息**: `本策略针对{Route Section}路段实施可变限速管控。在{Time Period}时段，对该路段实施限速{Speed}km/h的速度管控。`
2. **策略目标**: `通过动态调整限速值，优化交通流量，提高道路通行效率，降低事故风险。`
3. **适用场景**: 根据时间段类型生成不同场景描述

**示例**:
```
本策略针对G4202 K40-K45路段实施可变限速管控。在早高峰时段，对该路段实施限速60km/h的速度管控。

策略目标：通过动态调整限速值，优化交通流量，提高道路通行效率，降低事故风险。

适用场景：高峰时段交通流量大、车速不均匀的快速路或高速公路路段。
```

### DHS (动态硬路肩) 策略

**格式**: 多段式描述

**段落结构**:
1. **基本信息**: `本策略针对{Route Section}路段实施动态硬路肩开放管控。在{Time Period}时段，根据交通流量情况，动态开放应急车道供正常车辆通行，以增加道路通行能力。`
2. **策略目标**: `在高峰时段或交通拥堵情况下，临时开放应急车道，增加车道容量，缓解交通压力。`
3. **安全保障**: `系统将实时监控路段状态，确保在非紧急情况下合理利用应急车道资源。`
4. **适用场景**: 根据时间段类型生成不同场景描述

**示例**:
```
本策略针对G4202 K40-K45路段实施动态硬路肩开放管控。在早晚高峰时段，根据交通流量情况，动态开放应急车道供正常车辆通行，以增加道路通行能力。

策略目标：在高峰时段或交通拥堵情况下，临时开放应急车道，增加车道容量，缓解交通压力。

安全保障：系统将实时监控路段状态，确保在非紧急情况下合理利用应急车道资源。

适用场景：高峰时段交通流量大、主线车道接近饱和的高速公路路段。
```

### TEC (收费站管控) 策略

**格式**: 多段式描述（支持入口名称和控制参数）

**段落结构**:
1. **基本信息**: `本策略针对{Entrance/Route Section}实施计量控制管控。在{Time Period}时段，通过调节入口匝道信号灯控制车辆进入主线的频率，平衡主线交通流量。`
2. **控制参数** (如果有): `信号周期设置为{Cycle Time}秒，绿灯时长{Green Time}秒。`
3. **策略目标**: `通过入口匝道计量控制，防止主线过度拥堵，维持主线交通流的稳定性和高效性。`
4. **适用场景**: 根据时间段类型生成不同场景描述

**示例**:
```
本策略针对成温入口实施计量控制管控。在早高峰时段，通过调节入口匝道信号灯控制车辆进入主线的频率，平衡主线交通流量。信号周期设置为60秒，绿灯时长20秒。

策略目标：通过入口匝道计量控制，防止主线过度拥堵，维持主线交通流的稳定性和高效性。

适用场景：高峰时段主线交通流量接近饱和、入口匝道汇入导致拥堵的快速路或高速公路。
```

### 时间段检测逻辑

**复用 Task 3.1 的逻辑**:
- 调用 `StrategyNameGenerator.detectTimePeriod(parameters)`
- 支持检测：早高峰、晚高峰、早晚高峰、全天、定时管控

### 路段信息提取

**复用 Task 3.1 的逻辑**:
- 调用 `StrategyNameGenerator.extractRouteSection(edges)`
- 格式：`G4202 K40-K45` 或 `SA2 K30-K35`

## 已知限制

1. **描述模板固定**:
   - 当前使用硬编码的描述模板
   - 未来可考虑从模板配置中读取自定义描述模板

2. **参数动态性**:
   - 描述中仅包含部分关键参数（如限速值、时间段、信号周期）
   - 未包含所有参数的详细信息（避免描述过长）

3. **多语言支持**:
   - 当前仅支持中文描述
   - 未来可扩展为多语言模板

4. **多路线路段**:
   - 如果选中的路段跨越多条路线，仅显示第一条路线代码
