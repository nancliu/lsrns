│  │ 指标       值    类型   │                                         │

│    └─ max  = max(72861, 72890, 72830)       = 72890                │

│  该方案的aggregated_metrics:                                        │
│  ┌─────────────────────────────────────────┐                      │

## 📐 改进率计算决策树

```
                        ┌─ 计算改进率
                        │
        ┌───────────────┴────────────────┐
        │                                │
        ↓                                ↓
   检查direction字段        (来自metric_config)
        │
        ├─────────────┬──────────────┬─────────────┐
        │             │              │             │
      higher        lower          neutral        其他
        │             │              │             │
        ↓             ↓              ↓             ↓
   rawChange    -rawChange         null        null
        │             │              │
    增加=改进     减少=改进        不计算
   速度↑快=好   等待↓少=好
   完成↑多=好   传送↓少=好
```

## 🔢 计算复杂度分析

```
输入数据量:
├─ summary.xml大小: ~3600行 (每秒一步)
├─ 仿真数: k = 3-10个 (多个种子)
├─ 指标数: m = 9个
└─ 方案数: p = 2-5个

处理步骤:

1️⃣ XML解析: O(3600 * m)
   └─ 扫描所有step，提取9个属性
   └─ 复杂度: O(n) where n = 3600

2️⃣ 聚合统计: O(k * m)
   └─ 对k个仿真，计算m个指标的mean/std/min/max
   └─ 复杂度: O(k*m) where k=3-10, m=9
   └─ 实际: ~27-90 次操作

3️⃣ 改进率计算: O(p * m)
   └─ 对p个方案，计算m个指标的改进率
   └─ 复杂度: O(p*m) where p=2-5, m=9
   └─ 实际: ~18-45 次操作

4️⃣ 总复杂度: O(3600 + k*m + p*m)
             = O(3600 + 90 + 45)
             = O(3735) ← XML解析是主要耗时

实际耗时:
├─ XML解析: ~50ms
├─ 聚合统计: ~10ms
├─ 改进率计算: ~5ms
└─ 总计: ~100-200ms (包括网络往返)
```

## 📊 性能优化潜力分析

```
当前瓶颈 (按时间排序)

1️⃣ XML解析 (~50ms) - 75%的总耗时
   ├─ 原因: 需要扫描3600行
   └─ 优化空间:
       ├─ 使用流式解析 (SAX) 而非树解析 (DOM)
       ├─ 只解析最后10个step，反向查找
       └─ 预先缓存已解析的文件

2️⃣ API网络往返 (~50-100ms)
   ├─ 原因: HTTP请求往返延迟
   └─ 优化空间:
       ├─ 启用GZIP压缩
       ├─ 实施结果缓存 (5分钟TTL)
       └─ 使用WebSocket保持连接

3️⃣ 前端渲染 (~20ms)
   ├─ 原因: DOM操作和Chart.js初始化
   └─ 优化空间:
       ├─ 使用虚拟滚动 (大数据时)
       ├─ 延迟加载图表
       └─ 使用Canvas而非SVG

总优化目标: 200ms → 50ms (4倍提升)
└─ XML解析: 50ms → 10ms (流式+缓存)
└─ 网络: 100ms → 30ms (缓存+压缩)
└─ 渲染: 20ms → 10ms (异步+虚拟化)
```
