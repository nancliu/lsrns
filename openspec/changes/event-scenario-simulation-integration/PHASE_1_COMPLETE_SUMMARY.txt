**Enhancement Needed:**
1. Add comparison across multiple control strategies (VSS vs TEC vs DHS vs NO_CONTROL)
2. Enhance EdgeData visualization with strategy comparison
3. Add summary.xml metrics aggregation across scenarios
4. Implement batch history view in monitoring tab

### 3. Backend API Enhancements

**New Endpoints Needed:**
1. POST /api/v1/simulation/batch-start-from-scenarios
   - Input: List of scenario_ids
   - Output: batch_id for monitoring

2. GET /api/v1/analysis/multi-scenario-comparison
   - Input: List of simulation_ids from different scenarios
   - Output: Comparative analysis across strategies

3. GET /api/v1/case/batch-history
   - Input: Optional filters (date range, strategy type)
   - Output: List of historical batches with results

### 4. Workflow Integration

**Complete Flow:**
1. Scenario Browser → Select multiple scenarios (e.g., same event with different strategies)
2. Case-Simulation-Center (Tab 1) → Batch create cases from scenarios
3. Case-Simulation-Center (Tab 2) → Launch batch simulations
4. Case-Simulation-Center (Tab 2) → Monitor real-time progress
5. Case-Simulation-Center (Tab 3) OR analysis_viewer.html → View multi-scenario analysis

**Current Gaps:**
- Need batch case creation modal
- Need batch simulation selection modal (partially implemented)
- Need analysis auto-start when simulations complete
- Need better integration between tabs
