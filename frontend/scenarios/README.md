**文件**: `scenario_browser.html`

**版本**: v1.0 (简化版)

**创建日期**: 2025-01-09

---

## 📋 功能概述

这是一个简化的场景库浏览器，用于查看和管理基于真实事件的交通仿真推演场景。

### 核心功能

✅ **场景浏览**
- 卡片式场景展示
- 清晰的事件类型和管控策略标识
- 实时统计信息

✅ **智能筛选**
- 按事件类型筛选（6种）
- 按管控策略筛选（3种）
- 关键词搜索
- 多种排序方式

✅ **场景详情**
- 事件信息查看
- 管控参数展示
- 效果评分显示
- 标签分类

✅ **仿真集成**
- 一键应用到批量仿真
- 快速启动仿真任务
- 自动调用API

## 🚀 使用方法

### 1. 启动后端服务

```bash
# 启动FastAPI服务
.\start_api.ps1
```

### 2. 访问场景浏览器

在浏览器中打开：

```
http://localhost:8000/frontend/scenarios/scenario_browser.html
```

### 3. 浏览场景

- 使用顶部筛选栏筛选场景
- 点击「查看详情」查看场景完整信息
- 点击「快速应用」直接启动批量仿真

### 4. 应用到仿真

场景应用会自动调用以下API：

```
POST /api/v1/batch-optimization/create-and-run
```

并自动跳转到批量仿真管理页面。

## 🎨 界面特性

### 统计卡片

- **总场景数**: 显示场景库总量
- **已仿真场景**: 显示已完成仿真的场景数
- **事件类型**: 显示覆盖的事件类型数
- **平均评分**: 显示所有已评分场景的平均分

### 场景卡片

每个场景卡片包含：
- 场景名称
- 事件类型徽章（颜色编码）
- 管控策略徽章
- 高速公路和位置信息
- 方向和持续时间
- 效果评分（如有）
- 仿真次数
- 操作按钮

### 评分系统

- 🟢 **优秀** (85-100分): 绿色徽章
- 🔵 **良好** (70-84分): 蓝色徽章
- 🟠 **一般** (70分以下): 橙色徽章
- ⚪ **未评分**: 灰色徽章

## ⚠️ 注意事项

1. **数据文件位置**
   - 确保 `output/scenarios/scenario_index.json` 存在
   - 如果文件不存在，会使用内置的模拟数据

2. **API依赖**
   - 应用到仿真功能需要后端API支持
   - 确保FastAPI服务正在运行

3. **浏览器兼容性**
   - 推荐使用现代浏览器（Chrome、Edge、Firefox）
   - 需要支持ES6语法
