# 仿真场景库浏览器 - 设计说明

## 概述

重新设计的场景库浏览器提供了丰富的功能，用于浏览、搜索、创建案例和执行仿真分析。界面采用清晰的分层设计，满足用户对场景库丰富度的展现需求。

## 主要功能模块

### 1. 统计卡片（顶部）

- **总场景数**：系统中全部可用场景数量
- **已创建案例**：已从场景创建过案例的场景数
- **事件类型**：系统中存在的事件类型种数
- **管控策略**：系统中存在的管控策略种数

这些卡片自动从场景库数据中计算，提供快速概览。

### 2. 二维分类筛选器

#### 事件类型维度
- 全部（默认）
- 交通事故
- 交通阻塞/流量激增
- 交通管制
- 地质灾害
- 车辆故障
- 恶劣天气

#### 管控策略维度
- 全部（默认）
- 无管控
- VSS（动态限速）
- DHS（应急车道）
- TEC（收费管控）

#### 额外筛选选项
- **只显示有案例的场景**：勾选后仅显示已创建过案例的场景
- **搜索框**：支持搜索场景ID、Report ID、位置、高速公路名称等关键信息

### 3. 场景列表表格

表格显示所有过滤后的场景，包含以下列：

| 列名 | 说明 |
|------|------|
| 场景ID | 唯一场景标识，单色代码样式显示 |
| 事件类型 | 彩色徽章显示，每种类型有独特颜色 |
| 管控策略 | 彩色徽章显示，无管控为灰色 |
| 位置信息 | 高速公路名称和具体位置 |
| 事件时间 | 事件开始时间和持续时长 |
| 操作 | 创建案例和分析两个按钮 |

#### 表格行为
- 悬停时高亮背景，提升交互反馈
- 清晰的视觉层次，易于扫描
- 所有列都是可见的，无需水平滚动（在合理的屏幕宽度下）

### 4. 快速创建案例模态框

点击表格中的"创建"按钮打开此模态框，预填充选中场景的信息。

#### 预填充信息（只读）
- 场景ID
- 场景名称
- 事件类型
- 管控策略

#### 可配置参数
- **仿真持续时长**：可覆盖场景默认配置（单位：小时，范围：1-24）
- **随机种子**：可指定或留空使用随机值
- **生成EdgeData数据**：必选（用于分析，默认勾选）
- **生成TripInfo数据**：可选，默认勾选
- **生成VehRoute数据**：可选，默认勾选

#### 工作流
1. 用户在场景列表中选择一个场景
2. 点击"创建"按钮
3. 模态框弹出并预填充场景信息
4. 用户可选地调整仿真参数
5. 点击"创建案例"提交API请求
6. 成功后跳转到案例管理页面（可选）

### 5. 仿真分析配置模态框

点击表格中的"分析"按钮打开此模态框，配置和启动仿真分析。

#### 左侧面板：场景信息
- 场景基本信息（只读）：ID、事件类型、管控策略、位置
- 事件时间信息（只读）：开始时间、结束时间、持续时长

#### 右侧面板：分析配置
- **对标场景配置**：
  - 与基线场景对比（无事件无管控）
  - 与无管控场景对比（事件但无管控）

- **分析重点**：
  - 道路段分析（EdgeData）：分析事件影响范围和管控效果
  - 行程分析（TripInfo）：分析车辆出行时间和速度变化

- **分析输出信息**（参考）：
  - 事件影响热力图
  - 管控策略效果对比
  - 流量改善统计数据
  - 时间序列变化曲线

### 6. 导航栏

- **刷新按钮**：重新加载场景库数据
- **案例管理按钮**：跳转到案例管理页面，查看所有已创建的案例

## 数据加载流程

1. 页面加载时从 `/output/scenarios/scenario_index.json` 获取场景列表
2. 若加载失败，使用内置模拟数据进行演示
3. 初始化筛选器事件监听
4. 更新统计卡片信息
5. 应用默认筛选（仅显示有案例的场景）并渲染场景列表

## 交互流程

### 筛选流程
1. 用户点击事件类型或管控策略的任一 chip 选项
2. 该选项变为活跃状态（蓝色背景）
3. 其他选项自动取消活跃状态
4. 自动触发筛选逻辑
5. 场景列表实时更新，显示符合筛选条件的场景
6. 场景计数自动更新

### 搜索流程
1. 用户在搜索框中输入关键字
2. 每次输入变化时触发搜索
3. 搜索范围包括：场景ID、Report ID、位置、高速公路名称
4. 场景列表实时更新
5. 支持模糊匹配（不分大小写）

### 创建案例流程
1. 用户在场景列表中找到目标场景
2. 点击该行的"创建"按钮
3. 快速创建模态框弹出，预填充场景信息
4. 用户可调整仿真参数（可选）
5. 点击"创建案例"按钮
6. 向后端API发送POST请求（`/api/v1/scenario/create-case-batch`）
7. 成功后显示案例ID并可跳转到案例管理页面

### 仿真分析流程
1. 用户在场景列表中找到目标场景
2. 点击该行的"分析"按钮
3. 仿真分析配置模态框弹出
4. 显示场景信息和事件时间
5. 用户选择对标场景和分析重点
6. 点击"开始分析"按钮
7. 向后端API发送POST请求（`/api/v1/scenario/run-analysis`）
8. 成功后显示分析ID

## 响应式设计

- **桌面端（1200px+）**：二维筛选器两列显示，表格所有列可见
- **平板端（768-1199px）**：筛选器适应性调整，表格可能需要水平滚动
- **移动端**：全宽布局，部分功能可能受限

## 样式设计亮点

### 颜色方案
- **事件类型**：每种类型有独特的徽章颜色
  - 事故：红色
  - 阻塞：橙色
  - 管制：蓝色
  - 地质：紫色
  - 故障：绿色
  - 天气：青绿色

- **管控策略**：
  - VSS：蓝色
  - DHS：绿色
  - TEC：橙色
  - 无管控：灰色

### 交互反馈
- Chip 按钮悬停时变为蓝色背景
- 活跃 chip 显示蓝色背景和白色文字
- 表格行悬停时轻微高亮
- 按钮有明确的视觉反馈

## API 集成

### 创建案例
```javascript
POST /api/v1/scenario/create-case-batch
{
    event_id: string,
    event_type: string,
    scenarios: Array<{
        scenario_id: string,
        event_location: object,
        control_strategy: object,
        output_config: object,
        time: object
    }>,
    network_file: string,
    od_file: string,
    taz_file: string,
    time_range: {start_time: string, end_time: string},
    simulation_type: string
}
```

### 仿真分析
```javascript
POST /api/v1/scenario/run-analysis
{
    scenario_id: string,
    compare_baseline: boolean,
    compare_no_control: boolean,
    analysis_focus: {
        edgedata: boolean,
        tripinfo: boolean
    }
}
```

## 未来改进方向

1. 添加分页功能（当场景数量很大时）
2. 支持场景列表导出（CSV、Excel）
3. 添加列自定义功能（显示/隐藏列）
4. 支持多选批量操作
5. 集成场景预览（小地图、事件轨迹可视化）
6. 添加收藏/标记功能
7. 支持自定义筛选保存

## 已知限制

1. 搜索支持精确匹配部分内容，不支持正则表达式
2. 表格在超小屏幕上可能需要水平滚动
3. 模拟数据量有限，实际使用时需连接真实后端API
4. 分析结果展示需要单独的结果页面（未在此实现）
