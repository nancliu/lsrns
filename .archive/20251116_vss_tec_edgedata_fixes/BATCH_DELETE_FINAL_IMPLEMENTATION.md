## 🔄 删除流程

### 用户操作
```
1. 进入批量创建页面
2. 看到事件卡片，如果该事件有已创建案例，显示"1个案例已创建" badge
3. 同时显示红色的"🗑️ 删除案例"按钮
4. 点击删除按钮
5. 确认删除
6. 等待删除完成
7. 显示删除结果
8. 页面自动刷新，按钮消失（因为案例已删除）
```

### 后端操作
```
API: DELETE /api/v1/case/{caseId}/delete-with-reset

对于每个要删除的case：
  1. 删除 cases/{caseId}/ 文件夹
  2. 从scenario_index.json清除该case的created_cases
  3. 返回删除统计
```
