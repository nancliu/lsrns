## 二、必填字段详细说明

### 2.1 toll_station_id（收费站编号）

**字段说明**：
- 收费站的唯一标识编号，通常为3位数字
- 用于在系统中唯一标识一个收费站
- 同一收费站的不同广场使用相同的toll_station_id

**填写规则**：
- 格式：纯数字，3位
- 取值范围：001-999
- 唯一性：每个编号对应一个物理收费站
- 示例：246（江油收费站）、247（贯山收费站）

**注意事项**：
- ⚠️ 不可重复使用已分配的编号
- ⚠️ 同一收费站的上下行、不同广场使用相同编号
- ✅ 如不确定编号，可暂时留空，由系统统一分配

---

### 2.2 station_name（收费站名称）

**字段说明**：
- 收费站的官方标准名称
- 用于系统显示和报告生成

**填写规则**：
- 格式：中文文本，不超过20个字符
- 命名规范：[地名]+收费站
- 示例：江油收费站、锦城湖收费站、成金收费站

**注意事项**：
- ✅ 使用路段公司统一的标准名称
- ✅ 避免使用简称或别名
- ✅ 不包含"入口"、"出口"等方向信息（方向由entrance_exit字段标识）

**常见错误**：
- ❌ 江油站入口 → ✅ 江油收费站
- ❌ 江油 → ✅ 江油收费站
- ❌ 246站 → ✅ 江油收费站

---

### 2.3 route_code（路线代码）

**字段说明**：
- 收费站所属的高速公路路线编码
- 遵循国家高速公路编码标准

**填写规则**：
- 格式：G + 4位数字
- 标准编码：按照《国家高速公路网命名和编号规则》
- 示例：
  - G4202（成都绕城高速）
  - G5（京昆高速）
  - G93（成渝环线高速）

**常用路线代码**：
| 路线代码 | 路线名称 | 简称 |
|----------|----------|------|
| G4202 | 成都绕城高速 | 成都绕城 |
| G5 | 京昆高速 | 京昆 |
| G93 | 成渝环线高速 | 成渝环线 |
| G76 | 厦蓉高速 | 厦蓉 |

**注意事项**：
- ✅ 使用国标路线代码，不使用地方代码
- ⚠️ 如收费站跨越多条路线，选择主要路线

---

### 2.4 section_code（路段代码）

**字段说明**：
- 收费站所在的具体路段编码
- 细化到路线的某一管理段

**填写规则**：
- 格式：路线代码 + 3位段号
- 示例：
  - G4202001（成都绕城第1段）
  - G4202002（成都绕城第2段）
  - G0512001（成乐高速某段）

**编码规则**：
- 前4位：路线代码（如G4202）
- 后3位：路段序号（001-999）

**如何确定路段代码**：
1. 查阅路段公司的路段划分文件
2. 根据收费站所在里程确定所属路段
3. 如不确定，可咨询路段管理部门

**注意事项**：
- ⚠️ 路段代码必须与实际管理段一致
- ✅ 同一路段的收费站使用相同的section_code

---

### 2.5 longitude（经度）

**字段说明**：
- 收费站入口/出口广场的地理经度坐标
- 采用WGS84坐标系（GPS标准坐标系）

**填写规则**：
- 格式：小数，保留6位小数
- 取值范围：102.0 ~ 108.0（四川省境内）
- 精度要求：小数点后6位（约精确到0.1米）
- 示例：104.734567

**获取方式**：
1. **高德地图/百度地图**：
   - 在地图上定位收费站广场位置
   - 右键点击获取坐标（需转换为WGS84）
   - 百度坐标需要转换，高德坐标基本可用

2. **GPS设备**：
   - 使用手持GPS设备现场测量
   - 确保设备设置为WGS84坐标系

3. **路段公司GIS系统**：
   - 从路段公司的地理信息系统导出
   - 确认坐标系为WGS84

**注意事项**：
- ⚠️ 必须使用WGS84坐标系，不接受其他坐标系
- ⚠️ 定位点应选择在收费广场中心或入口栏杆处
- ✅ 同一收费站的不同广场可能有不同经度
- ✅ 保留6位小数（如：104.734567）

**坐标系转换**：
- 百度坐标（BD09）→ WGS84：需要转换
- 高德/谷歌坐标（GCJ02）→ WGS84：需要转换
- GPS原始坐标（WGS84）：无需转换

**常见错误**：
- ❌ 104.73（精度不够） → ✅ 104.734567
- ❌ 使用百度坐标未转换 → ✅ 转换为WGS84
- ❌ 定位在收费站办公楼 → ✅ 定位在收费广场

---

### 2.6 latitude（纬度）

**字段说明**：
- 收费站入口/出口广场的地理纬度坐标
- 采用WGS84坐标系

**填写规则**：
- 格式：小数，保留6位小数
- 取值范围：26.0 ~ 34.0（四川省境内）
- 精度要求：小数点后6位
- 示例：31.765432

**填写要求**：
- 与经度配套使用，定位同一地点
- 纬度数值应与收费站实际地理位置匹配
- 成都地区一般在30-31度之间
- 绵阳地区一般在31-32度之间

**验证方法**：
1. 在地图上标注经纬度坐标
2. 检查标注点是否在收费站位置
3. 确认所在城市、区县是否正确

**注意事项**：
- ⚠️ 纬度与经度必须匹配同一位置
- ⚠️ 检查是否在四川省范围内（26-34度）
- ✅ 同一收费站不同广场纬度可能略有不同

---

### 2.7 entrance_exit（出入口类型）

**字段说明**：
- 标识该记录对应的是收费站入口还是出口
- 用于区分车辆进出高速公路的方向

**填写规则**：
- 固定取值：entrance 或 exit
- entrance：入口（车辆进入高速公路）
- exit：出口（车辆离开高速公路）
- 示例：entrance

**填写说明**：
- 本次采集主要关注**入口（entrance）**
- 入口：连接匝道到主线的位置
- 出口：主线到匝道的位置

**一个收费站的可能情况**：
1. **只有入口**：仅entrance记录
2. **只有出口**：仅exit记录
3. **既有入口又有出口**：两条记录，分别标注

**注意事项**：
- ✅ 本次数据采集重点为**entrance（入口）**
- ✅ 如果一个收费站有多个入口广场，每个广场一条记录
- ✅ 大写或小写均可，建议使用小写

**常见场景**：
| 场景 | entrance | exit | 说明 |
|------|----------|------|------|
| 标准互通 | ✓ | ✓ | 有上下匝道 |
| 枢纽互通 | ✓ | ✓ | 多方向 |
| 服务区出入口 | ✓ | ✓ | 服务区连接 |
| 单向出口 | | ✓ | 仅下高速 |

## 三、可选字段详细说明

### 3.1 square_code（广场编码）

**字段说明**：
- 收费广场的详细编码
- 用于区分同一收费站的不同广场

**填写规则**：
- 格式：按照交通部或路段公司标准编码
- 示例：G42015100200801010
- 长度：通常为17-20位

**编码结构（参考）**：
```
G4202 - 1 - 5 - 1 - 001 - 008 - 01 - 010
│       │   │   │   │     │     │    └─ 广场序号
│       │   │   │   │     │     └────── 出入口类型
│       │   │   │   │     └──────────── 收费站序号
│       │   │   │   └────────────────── 路段序号
│       │   │   └────────────────────── 省份代码
│       │   └────────────────────────── 高速类型
│       └────────────────────────────── 分段号
└────────────────────────────────────── 路线代码
```

**注意事项**：
- 🔵 此字段为可选，如无统一编码可留空
- ✅ 如有路段公司的标准编码，建议填写
- ✅ 有助于与其他系统对接

---

### 3.2 taz_id（交通小区ID）

**字段说明**：
- 交通分析区域（Traffic Analysis Zone）的唯一标识
- 用于交通规划和OD分析

**填写规则**：
- 格式：根据交通规划部门的TAZ划分
- 通常与square_code相同或相关
- 示例：G42015100200801010

**应用场景**：
- 交通需求分析
- OD矩阵生成
- 流量分配计算

**注意事项**：
- 🔵 此字段为可选
- ✅ 如路段公司有TAZ划分数据，建议提供
- ✅ 有助于提高仿真精度

---

### 3.3 remarks（备注）

**字段说明**：
- 补充说明信息
- 用于记录特殊情况或额外信息

**填写内容（可选）**：
- 广场编号：入口广场1、入口广场2
- 方向信息：成都方向、绵阳方向
- 特殊说明：临时收费站、新建收费站
- 其他信息：封闭时间、改造情况

**填写示例**：
- "入口成都方向"
- "2024年新建"
- "节假日临时开放"
- "连接绕城外环"

**注意事项**：
- 🔵 此字段为可选，非必填
- ✅ 简洁明了，不超过50字
- ✅ 重点记录影响管控的特殊信息

## 六、常见问题FAQ

### Q1: 如何确定收费站的toll_station_id？
**A**: 如果收费站已有编号，使用现有编号。如果是新站或编号未知，可暂时留空，由系统统一分配。

### Q2: 一个收费站有多个入口广场，如何填写？
**A**: 每个广场填写一条记录，使用相同的toll_station_id，但经纬度、square_code、remarks不同。

### Q3: 如何获取准确的WGS84坐标？
**A**:
1. 使用高德地图API转换
2. 使用专业GPS设备现场测量
3. 联系路段公司GIS部门提供

### Q4: 路段代码section_code如何确定？
**A**: 查阅路段公司的路段划分文件，或咨询路段管理部门。通常一个管理段对应一个section_code。

### Q5: 可选字段必须填写吗？
**A**: 不必须。但建议尽量填写square_code和taz_id，有助于提高数据完整性。

### Q6: 提交后发现错误怎么办？
**A**: 及时联系项目组，提供修正数据。我们会更新数据库并通知您。
