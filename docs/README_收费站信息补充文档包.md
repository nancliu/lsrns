## 📊 数据需求概览

### 缺失的收费站数量
- **总数**：41个
- **分布**：成都绕城段16个，其他路段25个

### 需要的信息字段
- 收费站编号（toll_station_id）
- 收费站名称（station_name）
- 路线代码（route_code）
- 经度/纬度（WGS84坐标）
- 出入口类型（entrance/exit）

### 预期成果
- 补充41个收费站信息
- 覆盖53个历史管控案例
- 将真实管控场景生成成功率从14%提升到100%

## ⚡ 快速操作

### 发送邮件（3分钟）

```bash
1. 打开邮件客户端
2. 复制"邮件发送模板.txt"的内容
3. 附加4个文档文件
4. 发送给路段公司技术部门
```

### 接收数据（验证）

```bash
1. 收到路段公司回复的CSV文件
2. 用Excel打开，检查必填字段是否完整
3. 在地图上验证经纬度坐标
4. 导入到toll_station_mapping.csv
```
