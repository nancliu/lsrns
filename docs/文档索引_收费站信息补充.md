### 2. 收费站信息采集表_模板.csv

**文件性质**：Excel/CSV数据模板
**记录数**：41行（对应41个缺失的收费站ID）
**字段数**：10个字段

**主要字段**：
```
toll_station_id, station_name, route_code, section_code,
longitude, latitude, entrance_exit, square_code, taz_id, remarks
```

**使用方法**：
1. 用Excel或WPS打开文件
2. 在每行填写对应收费站的信息
3. 保存为CSV格式（UTF-8编码）
4. 回复邮件并附上填写完成的文件

**注意事项**：
- ⚠️ 不要删除表头行
- ⚠️ toll_station_id列已预填，不要修改
- ⚠️ 保存时选择"CSV UTF-8"格式
- ✅ 可以不填写可选字段（square_code, taz_id, remarks）

## 🎯 使用流程

### 标准发送流程

```
1. 准备文档包
   ├─ 检查5个文件是否齐全
   └─ 确认文件格式正确

2. 起草邮件
   ├─ 复制"邮件发送模板.txt"内容
   ├─ 修改收件人信息
   └─ 附加文档1-4

3. 发送邮件
   ├─ 发送给路段公司技术部门
   ├─ 抄送相关领导
   └─ 设置已读回执（可选）

4. 跟进反馈
   ├─ 记录发送时间和收件人
   ├─ 1周后跟进确认是否收到
   └─ 解答路段公司的疑问

5. 接收数据
   ├─ 检查数据完整性
   ├─ 验证数据准确性
   └─ 导入系统数据库
```

## ⚠️ 注意事项

### 文档发送注意事项

1. **保密性**：文档包含系统内部数据结构信息，注意保密
2. **准确性**：发送前确认路段公司联系方式准确
3. **及时性**：建议在工作日上午发送，提高查收率
4. **礼貌性**：使用礼貌、专业的语气
