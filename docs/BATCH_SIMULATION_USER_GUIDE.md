# 批量仿真 - 用户使用指南

## 新功能：上下双标签栏导航

### 什么是双标签栏？

批量仿真页面现在在**页面顶部**和**屏幕底部**都有标签栏，方便您快速切换三种视图：

- **配置** - 创建和配置批量仿真
- **批次监控** - 查看仿真进度和历史
- **结果** - 查看仿真结果和分析

---

## 使用场景

### 场景 1: 快速配置（在页面顶部）
1. 打开批量仿真页面
2. 在**顶部标签栏**点击"配置"
3. 选择案例、方案、配置参数
4. 点击"创建批次"

### 场景 2: 监控进度（无需滚动）
1. 批次创建后，点击**底部标签栏**的"批次监控"
2. 无论页面多长，底部标签栏始终可见
3. 查看进度、实时曲线、任务列表
4. 可以向下滚动查看更多历史批次

### 场景 3: 查看结果（从任何位置）
1. 仿真完成后，点击**顶部或底部标签栏**的"结果"
2. 查看峰值曲线、方案对比表
3. 不用滚动回顶部就能切换其他视图

---

## 标签栏特性详解

### 顶部标签栏（普通）
- **位置**: 页面上方
- **行为**: 自然流动，跟随页面滚动
- **优点**: 简洁清爽，不占用额外层级
- **适用**: 页面开始处的导航

```
[配置] [批次监控] [结果]  <- 页面顶部，自然流动
─────────────────────────
内容区域
```

### 底部标签栏（Fixed）
- **位置**: 屏幕底部
- **行为**: 始终显示在屏幕底部，不受页面滚动影响
- **优点**: 始终可点击，最快速访问
- **适用**: 在查看长内容时快速切换

```
内容区域
（可以很长）
─────────────────────────
[配置] [批次监控] [结果]  <- 始终在屏幕底部
```

## 快速操作说明

### 切换视图

| 操作 | 方法 |
|------|------|
| 顶部标签切换 | 滚动到页面顶部，点击标签栏选项 |
| 底部标签切换 | 点击屏幕底部的固定标签栏（始终可见） |
| 推荐方式 | 使用底部标签栏，无需滚动 |

### 标签状态显示

- **蓝色/高亮**: 当前活跃的标签
- **灰色**: 非活跃标签

```
顶部：[配置] [批次监控] [结果]
底部：[配置] [批次监控] [结果]

当前查看"配置"时：
顶部：[配置✓] [批次监控] [结果]
底部：[配置✓] [批次监控] [结果]
```

### 完整的批量仿真流程

## 屏幕尺寸适配

### 桌面/大屏幕 (> 768px)
- ✅ 顶部标签栏显示（普通）
- ✅ 底部标签栏显示（固定）
- 推荐使用底部标签栏快速切换（始终可见）

### 平板/中屏幕 (768px - 1024px)
- ✅ 顶部标签栏显示
- ⚠️ 底部标签栏可见但可能需要滚动
- 推荐使用顶部标签栏或滚动后使用底部标签栏

### 手机/小屏幕 (< 768px)
- ✅ 顶部标签栏显示（普通）
- ❌ 底部标签栏隐藏（自动响应）
- 使用顶部标签栏切换视图

## 常见问题

### Q1: 为什么有两个标签栏？
**A**: 为了提高操作效率。当页面内容较多时，无需频繁滚动就能快速切换视图。

### Q2: 两个标签栏的功能一样吗？
**A**: 是的，完全相同。你可以只使用其中一个，或根据情况灵活切换。

### Q3: 底部标签栏会遮挡内容吗？
**A**: 不会。内容自动添加了底部填充（padding），所有重要内容都可见。

### Q4: 移动设备上怎么使用？
**A**: 移动设备（<768px）自动隐藏底部标签栏，只显示顶部标签栏，提供更好的移动体验。

### Q5: 如何快速回到某个视图？
**A**: 两个标签栏都始终可见（大屏幕），直接点击即可切换，无需多次滚动。
