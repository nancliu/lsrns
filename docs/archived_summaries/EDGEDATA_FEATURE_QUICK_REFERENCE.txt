WHAT IS THIS FEATURE?
================================================================================

Unified edgeData generation that:
  • Aggregates event impact edges + control strategy edges
  • Generates ONE edgeData.add.xml per event (shared across scenarios)
  • Monitors ~125 smart-selected edges instead of 5,000 all edges
  • 98% data reduction, 59% faster multi-scenario analysis
