ARCHITECTURE OVERVIEW
================================================================================

The feature consists of 3 main components:

1. EdgeImpactAggregator (shared/utilities/edge_aggregator.py)
   ├─ Extracts event impact edges (4 methods available)
   ├─ Extracts strategy-specific edges (VSS/TEC/DHS)
   ├─ Merges and deduplicates
   └─ Validates against network file

2. Enhanced SUMO Utils (shared/utilities/sumo_utils.py)
   ├─ generate_edgedata_xml_for_case() - NEW
   └─ generate_sumocfg_for_simulation() - ENHANCED

3. Case Service Orchestration (api/services/case_service.py)
   ├─ _generate_event_edgedata() - NEW
   ├─ _load_scenario_strategies() - NEW
   └─ _get_or_create_event_case() - ENHANCED

KEY DESIGN DECISIONS
================================================================================

✓ Single edgeData per event (not per scenario)
  Rationale: Event impacts identical across scenarios, enables fair comparison

✓ Aggregate ALL strategy impacts
  Rationale: Comprehensive monitoring, detect secondary effects

✓ Flexible impact zone methods
  Options: immediate, radius_1_hop, radius_2_hops, explicit

✓ Generate at case creation time
  Rationale: Leverages event metadata, async background process

✓ Store aggregation metadata
  Rationale: Debugging, auditing, future changes

✓ 100% backward compatible
  Rationale: Existing cases unaffected, new parameter optional
