```
   ├─ 数据加载 (loadScenarios)
   ├─ 筛选逻辑 (applyFilters)

   ├─ 交互处理 (openQuickCreate, etc)
   └─ API 集成 (submit* 函数)
```

### 关键设计决策

1. **表格而非卡片**
   - 原因：信息密度提高 300%
   - 效果：一屏显示 10+ 场景 vs 原来的 3 个

2. **Chip 选择器而非下拉菜单**
   - 原因：视觉化+多选友好
   - 效果：更直观的筛选交互

3. **客户端筛选而非服务器筛选**
   - 原因：低延迟，一次加载所有数据
   - 效果：即时反馈

4. **两个独立模态框**
   - 原因：清晰的用户意图分离
   - 效果：创建和分析流程独立
