2. **前端数据遗漏**
   - 默认分页只加载10条，遗漏第2页的OD案例

3. **筛选逻辑不完整**
   - 未能识别所有事件场景案例类型
   - 修复文件: `batch_simulation.js`, `script.js`, `scenario_browser.js`

4. **404错误（无效case_id）**
   - disabled option缺少明确的value属性
   - 自动选择逻辑未验证option有效性
   - API调用前未验证case_id格式
   - 修复文件: `batch_simulation.js`
