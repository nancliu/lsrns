## 📋 使用说明

### 推荐工作流：先看详情，再创建案例

1. **打开场景浏览器**
   ```
   http://localhost:8000/frontend/scenarios/scenario_browser.html
   ```

2. **第一步：查看场景详情（确认无误）**
   - 点击场景行左边的"详情"按钮
   - 查看完整的场景信息（5个分类）
   - 人工确认所有信息完整和正确
   - 关闭详情模态框

3. **第二步：创建仿真案例**
   - 点击场景行右边的"创建"按钮
   - 场景ID、事件类型、策略、时间范围自动填充（只读）
   - 检查输出配置（默认都勾选）：
     - EdgeData：路段流量和速度数据 ✓
     - TripInfo：车辆行程信息 ✓

4. **第三步：确认并创建**
   - 根据需要修改输出配置（可选）
   - 点击"✓ 创建"按钮
   - 系统原子性地创建案例和仿真配置
   - 完成后显示成功消息和案例ID
   - 表格自动刷新，显示新案例状态

**工作流特点**:
- 查看详情 → 人工确认 → 无需修改参数 → 一键创建
- 不会自动导航，可继续在场景列表进行其他操作

### 查看场景详情（详细说明）

1. **点击场景行左边的"详情"按钮**
   - 打开场景详情模态框
   - 立即显示基础信息
   - 异步加载 event_description.json（完整事件数据）

2. **场景详情模态框包含5个分类**

   **📋 基本信息**（蓝色）
   - 场景ID、事件ID、事件类型、管控策略
   - 事件描述 ✨（从 event_description.json 加载）

   **🌍 事件发生地点与时间**（绿色）
   - 道路 ✨、方向 ✨、里程 ✨
   - 路网Edge ID ✨、交叉口ID ✨
   - （✨ = 从 event_description.json 动态加载）

   **⏰ 时间信息**（橙色）
   - 开始时间 ✨、结束时间 ✨、持续时长 ✨

   **⚠️ 事件影响**（红色）
   - 影响车道 ✨（从 event_description.json 提取）
   - 车道ID ✨

   **🎛️ 管控策略详情**（紫色）
   - 策略类型、策略参数（JSON格式）

3. **点击"关闭"或×关闭模态框**

### 数据来源说明

**两层数据加载机制**:
- **基础数据**: 从 scenario_index.json 立即显示（快速）
- **详细数据**: 从 event_description.json 异步加载（完整）

**自动回退机制**:
- 如果 event_description.json 不存在或加载失败 → 自动使用 scenario_index.json 数据
- 用户无需感知，始终看到有效数据

## 💡 已知事项

### 原子性保证
- 创建案例和仿真配置在单一事务中完成
- 成功创建后，scenario_index.json会更新created_cases数组
- case元数据和simulation_metadata.json同时创建

### OD处理
- 仍然异步进行，不会阻塞用户界面
- 案例创建成功不表示OD处理完成
- 可在案例管理页面查看进度

### 失败处理
- 创建失败会显示具体错误信息
- 按钮状态自动恢复
- 用户可重试创建
