# 归档的UI页面

**归档日期**: 2025-01-09

**原因**: 简化工作流程，减少维护成本

---

## 📁 归档文件

### 1. event_extraction.html (98KB)

**原功能**：
- 从CSV读取事件列表
- 手动选择事件
- 配置管控策略（VSS/DHS/TEC）
- 生成场景配置JSON

**替代方案**：
- ✅ 使用Python脚本批量处理（更高效）
- ✅ 参考代码：`docs/scenarios_library/PROJECT_WORKFLOW.md` 中的示例

**删除原因**：
- 399个事件手动配置效率极低
- Python脚本可以智能筛选和批量生成
- 减少维护成本

---

### 2. scenario_library.html (43KB)

**原功能**：
- 四维筛选（事件×管控×路段×时间）
- 场景列表展示
- 场景代码编辑
- 复杂的案例管理

**替代方案**：
- ✅ 使用简化版 `frontend/scenarios/scenario_browser.html`
- ✅ 保留核心浏览和应用功能
- ✅ 代码量减少65%（43KB → 15KB）

**简化原因**：
- 四维筛选过于复杂，实际使用率低
- 场景编辑应通过脚本完成
- 简化后更易维护

---

### 3. impact_analysis.html (27KB)

**原功能**：
- 场景选择
- 对比分析（Baseline/Event Only/Event+Control）
- 图表可视化
- 地图热力图

**替代方案**：
- ✅ 使用现有的 `batch_optimization.html`
- ✅ 使用现有的 `strategy_ranking.html`
- 🔄 后期可集成到 `scenario_browser.html`

**暂缓原因**：
- 现有界面已提供核心分析功能
- 避免功能重复
- 优先完成核心工作流
