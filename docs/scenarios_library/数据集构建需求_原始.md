## 数据集2：仿真推演典型场景数据集 - 数据需求说明

### 核心需求

覆盖典型场景6类以上，包括：

* **6类事件** ：交通事故、恶劣天气、地质灾害、流量激增、临时道路养护、路面异常
* **3类管控** ：动态速度限制(VSS)、应急车道开放（DHS）、收费入口管控（TEC）

---

### 建议的数据结构2

#### 1. 场景基础信息表

 **表名建议** ：`scenario_catalog` 或存储为CSV文件

| 字段名              | 类型         | 说明           | 示例                                   |
| ------------------- | ------------ | -------------- | -------------------------------------- |
| scenario_id         | varchar(50)  | 场景唯一标识   | `SC001`                              |
| scenario_name       | varchar(100) | 场景名称       | `雨天高速公路交通事故`               |
| scenario_category   | varchar(50)  | 场景类别       | `事件-交通事故` 或 `管控-动态限速` |
| description         | text         | 场景描述       | 详细的场景说明                         |
| network_section     | varchar(100) | 发生路段       | `G4202-K100-K120`                    |
| simulation_duration | integer      | 仿真时长（秒） | `3600`                               |
| created_date        | date         | 创建日期       | `2024-10-15`                         |

 **预计记录数** ：至少9条（6事件+3管控）

---

#### 2. 事件详细配置表

 **表名建议** ：`scenario_events`

| 字段名               | 类型         | 说明                   | 示例                                                                                                                                                                                                           |
| -------------------- | ------------ | ---------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| event_id             | varchar(50)  | 事件ID                 | `EVT001`                                                                                                                                                                                                     |
| scenario_id          | varchar(50)  | 关联场景ID             | `SC001`                                                                                                                                                                                                      |
| event_type           | varchar(50)  | 事件类型               | `traffic_accident`（交通事故）`<br>severe_weather`（恶劣天气）`<br>geological_disaster`（地质灾害）`<br>traffic_surge`（流量激增）`<br>road_maintenance`（道路养护）`<br>road_anomaly`（路面异常） |
| event_subtype        | varchar(50)  | 事件子类型             | `车辆追尾`、`暴雨`、`山体滑坡`、`节假日流量`                                                                                                                                                           |
| location_type        | varchar(20)  | 位置类型               | `edge`（路段）、`junction`（节点）                                                                                                                                                                         |
| location_id          | varchar(100) | 位置标识               | edge_id 或 junction_id                                                                                                                                                                                         |
| start_time           | integer      | 发生时间（秒）         | `600`                                                                                                                                                                                                        |
| duration             | integer      | 持续时间（秒）         | `1800`                                                                                                                                                                                                       |
| severity_level       | integer      | 严重程度（1-5）        | `3`                                                                                                                                                                                                          |
| affected_lanes       | text         | 影响车道               | `lane_0,lane_1`                                                                                                                                                                                              |
| speed_reduction      | numeric(5,2) | 速度降低比例           | `0.50`（降低50%）                                                                                                                                                                                            |
| capacity_reduction   | numeric(5,2) | 通行能力降低比例       | `0.60`（降低60%）                                                                                                                                                                                            |
| visibility_reduction | numeric(5,2) | 能见度降低（恶劣天气） | `0.30`                                                                                                                                                                                                       |
| lane_closure         | boolean      | 是否封闭车道           | `true`                                                                                                                                                                                                       |
| parameters           | jsonb        | 其他参数（JSON格式）   | `{"weather_type": "heavy_rain", "intensity": 8}`                                                                                                                                                             |

 **预计记录数** ：10-30条（每类事件至少1-2个实例）

---

#### 3. 管控策略配置表

 **表名建议** ：`scenario_control_strategies`

| 字段名                   | 类型         | 说明                     | 示例                                                                                |
| ------------------------ | ------------ | ------------------------ | ----------------------------------------------------------------------------------- |
| control_id               | varchar(50)  | 管控ID                   | `CTRL001`                                                                         |
| scenario_id              | varchar(50)  | 关联场景ID               | `SC007`                                                                           |
| control_type             | varchar(50)  | 管控类型                 | `vsl`（动态限速）`<br>dynamic_lane`（动态车道）`<br>flow_control`（流量管控） |
| control_subtype          | varchar(50)  | 管控子类型               | `应急车道开放`、`货车限行`、`入口限流`                                        |
| location_type            | varchar(20)  | 位置类型                 | `edge`、`junction`、`tollsquare`                                              |
| location_id              | varchar(100) | 位置标识                 | edge_id、收费广场编码                                                               |
| activation_time          | integer      | 启动时间（秒）           | `1200`                                                                            |
| deactivation_time        | integer      | 结束时间（秒）           | `2700`                                                                            |
| trigger_condition        | text         | 触发条件                 | `流量>1500 veh/h`                                                                 |
| vsl_speed_limit          | numeric(5,2) | 限速值（km/h，VSL专用）  | `60.00`                                                                           |
| lane_change              | text         | 车道变更（动态车道专用） | `emergency_lane_open`（应急车道开放）                                             |
| flow_limit_rate          | numeric(5,4) | 限流比例（流量管控专用） | `0.7000`（限制到70%）                                                             |
| vehicle_type_restriction | text         | 车型限制                 | `truck_h5,truck_h6`（限制大货车）                                                 |
| parameters               | jsonb        | 其他参数                 | `{"ramp_metering_rate": 0.8}`                                                     |

 **预计记录数** ：6-15条（每类管控至少2-3个实例）

---

#### 4. 场景仿真结果统计表（可选）

 **表名建议** ：`scenario_simulation_results`

| 字段名              | 类型          | 说明                  | 示例                    |
| ------------------- | ------------- | --------------------- | ----------------------- |
| result_id           | varchar(50)   | 结果ID                | `RES001`              |
| scenario_id         | varchar(50)   | 场景ID                | `SC001`               |
| simulation_run_id   | varchar(50)   | 仿真运行批次          | `RUN_20241015_001`    |
| total_vehicles      | integer       | 总车辆数              | `85000`               |
| peak_vehicles       | integer       | 峰值在网车辆          | `12500`               |
| avg_speed           | numeric(10,2) | 平均速度（km/h）      | `72.30`               |
| avg_travel_time     | numeric(10,2) | 平均行程时间（秒）    | `1456.80`             |
| total_delay         | numeric(15,2) | 总延误（车·秒）      | `125000.00`           |
| queue_length_max    | numeric(10,2) | 最大排队长度（米）    | `2500.00`             |
| throughput          | integer       | 通行量（辆）          | `78900`               |
| effectiveness_score | numeric(5,2)  | 管控效果评分（0-100） | `82.50`               |
| simulation_date     | timestamp     | 仿真运行时间          | `2024-10-15 14:30:00` |

 **预计记录数** ：9+条（每个场景至少1条结果）
