┌──────────────────────────────────────────────────────────────────────────┐
│ 💡 故障排查                                                              │
└──────────────────────────────────────────────────────────────────────────┘

问题: 按钮显示省略号
解决: 这是正常的响应式行为，文字超过宽度会自动显示省略号

问题: 按钮换行了
解决: 检查 flex-wrap 是否被覆盖，确保 nowrap 有效

问题: 某个状态没有按钮
解决: 检查 batch_simulation.js 1441-1464 行是否有该状态分支

问题: 样式不生效
解决: 清除浏览器缓存，重新加载 CSS 文件

问题: 新按钮不显示
解决: 检查 JavaScript 控制台是否有错误，验证 status 值
