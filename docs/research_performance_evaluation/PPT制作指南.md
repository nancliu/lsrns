# PowerPoint演示文稿制作指南

## 方法一：使用Markdown转PowerPoint工具

### 推荐工具：Marp

**安装**:
```bash
npm install -g @marp-team/marp-cli
```

**转换命令**:
```bash
cd docs/research_performance_evaluation
marp 演示文稿.md -o 演示文稿.pptx --theme default
```

### 或使用在线工具

**Marp Online**: https://web.marp.app/
1. 打开网站
2. 粘贴 `演示文稿.md` 内容
3. 点击"Export" → 选择PPTX格式

---

## 方法二：手动在PowerPoint中创建

### 步骤

1. **创建新演示文稿**
   - 打开PowerPoint
   - 选择空白演示文稿
   - 设置页面尺寸: 16:9

2. **设置主题**
   - 设计 → 主题 → 选择专业主题（如"Ion"或"Facet"）
   - 主色调：深蓝、绿色、橙色

3. **按页面添加内容**
   - 参考 `演示文稿.md` 的结构
   - 共约25页（含备用页）

### 关键页面制作要点

#### 封面页
```
标题: 路网交通仿真推演典型场景集构建
副标题: 研究绩效评价汇报
日期: 2025年11月
汇报人: 交通仿真团队
```

#### 目录页
使用SmartArt "垂直项目符号列表"

#### 数据页面
- 插入图片: `charts/` 文件夹中的PNG图片
- 调整大小: 占页面60-70%
- 添加标题和简短说明

#### 文字页面
- 标题: 28-32pt
- 正文: 18-20pt
- 项目符号: 使用✅❌标记增强视觉效果

## PPT设计规范

### 配色方案
- **主色**: #1E3A8A (深蓝)
- **辅色**: #2ECC71 (绿色)、#F59E0B (橙色)、#E74C3C (红色)
- **背景**: 白色或浅灰 (#F8F9FA)

### 字体
- **标题**: 微软雅黑 Bold, 28-32pt
- **正文**: 微软雅黑 Regular, 18-20pt
- **数据标注**: 微软雅黑 Bold, 14-16pt

### 页面布局
- **标题区**: 页面顶部，占10-15%
- **内容区**: 页面中部，占70-80%
- **页脚**: 页面底部，页码+日期

## 演讲提示

### 时间分配（10分钟演讲）
- 封面+目录: 30秒
- 核心问题分析: 2分钟
- 技术创新突破: 3分钟
- 主要产出成果: 2分钟
- 应用价值展示: 1.5分钟
- 总结与展望: 1分钟

### 演讲要点
1. **开场**: 一句话点出核心问题
2. **技术**: 重点讲3大创新，用数据说话(99.7%提升)
3. **成效**: 强调449场景、>90%覆盖率
4. **案例**: 展示典型应用，突出实际效果
5. **结尾**: 总结核心数据，展望未来
