## 使用说明

### 如何引用这些文档

**在研究报告中:**
```
技术细节详见项目设计文档[1]和场景生成指南[2]。

参考文献:
[1] Phase 2 Design Document. D:\projects\OD_SIM\openspec\changes\event-scenario-simulation-integration\design.md
[2] Scenario Generation Guide. D:\projects\OD_SIM\docs\scenarios_library\SCENARIO_GENERATION_GUIDE.md
```

**在PPT中:**
```
技术架构详见设计文档
(openspec/changes/event-scenario-simulation-integration/design.md)
```
