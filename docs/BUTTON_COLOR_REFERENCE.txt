用途:      启动仿真、重新启动

设计意图: 蓝色代表"信任"和"行动"，强调这是主要操作流程

┌──────────────────────────────────────────────────────────────────────────┐
│ ✨ 交互效果说明                                                          │
└──────────────────────────────────────────────────────────────────────────┘

所有按钮的交互效果:

默认状态:
  • 显示静态颜色
  • 光标为 pointer
  • 略微抬起阴影

Hover 状态:
  • 背景颜色变化
  • 文字颜色变化
  • 阴影增强
  • 按钮向上移动 1px

Active 状态:
  • 恢复到原始位置
  • 保持 Hover 颜色

Disabled 状态:
  • 透明度 60%
  • 光标为 not-allowed
  • 不响应点击

如需修改颜色，编辑文件:
  frontend/control/css/simulations.css (L754-819)

修改步骤:
  1. 找到对应的 .btn-small.btn-* 类
  2. 修改 background、color、border-color 值
  3. 更新 :hover 状态的颜色
  4. 测试对比度符合 WCAG AA 标准

  .btn-small.btn-primary {
      background: #c2185b;  ← 改这里
      color: white;
      border-color: #c2185b;  ← 和这里
  }

┌──────────────────────────────────────────────────────────────────────────┐
│ 📞 常见问题                                                              │
└──────────────────────────────────────────────────────────────────────────┘

Q: 为什么要使用四种颜色?
A: 不同颜色代表不同操作类型和风险级别，帮助用户快速识别按钮功能。

Q: 颜色的选择有标准吗?
A: 有，遵循 Bootstrap、Material Design 等成熟 UI 框架的颜色约定。

Q: 可以改变颜色吗?
A: 可以，但建议保持颜色含义的一致性，避免用户混淆。

Q: 颜色在深色模式下显示正常吗?
A: 当前设计针对浅色背景。深色模式支持可作为未来升级。

Q: 无序游客的视觉能否区分这些颜色?
A: 是的，所有颜色对比度都符合无障碍标准 (WCAG AA)。
