## 1. 基准流量查询

### 1.1 查询单个门架的24小时流量模式（工作日）

```sql
SELECT
    gantry_id,
    hour AS time_hour,
    mean AS avg_flow_per_5min,
    median AS median_flow,
    p85 AS p85_flow,
    p95 AS p95_flow,
    stddev AS flow_std,
    truck_ratio,
    avg_speed,
    free_flow_speed,
    passenger_small,
    passenger_large,
    truck_small,
    truck_large,
    sample_count,
    batch_id
FROM baseline.baseflow_pattern_gantry
WHERE gantry_id = 'G000551001000110010'
  AND pattern_type = 'workday'
ORDER BY hour;
```

**用途**: 仿真单门架24小时流量注入配置

**输出字段说明**:
- `avg_flow_per_5min`: 平均流量（辆/5分钟）
- `p85_flow`: 85分位数流量（用于容量估算）
- `truck_ratio`: 货车占比（0-1，如0.23 = 23%）
- `sample_count`: 样本数（0表示补充数据）

---

### 1.2 查询某路线所有门架的早高峰流量（7-9点）

```sql
SELECT
    g.gantry_id,
    g.gantry_name,
    d.route_code,
    g.hour,
    g.mean AS avg_flow,
    g.p85 AS p85_flow,
    g.truck_ratio,
    g.avg_speed,
    g.estimated_capacity,
    ROUND(g.mean / NULLIF(g.estimated_capacity, 0) * 100, 2) AS capacity_util_pct
FROM baseline.baseflow_pattern_gantry g
JOIN dim.all_gantry_228 d ON g.gantry_id = d.gantry_id
WHERE d.route_code = 'G4202'
  AND g.pattern_type = 'workday'
  AND g.hour BETWEEN 7 AND 9
ORDER BY d.stake_number, g.hour;
```

**用途**: 路线级流量全景分析

### 1.3 对比不同模式（工作日 vs. 周末）流量差异

```sql
SELECT
    gantry_id,
    hour,
    MAX(CASE WHEN pattern_type = 'workday' THEN mean END) AS workday_flow,
    MAX(CASE WHEN pattern_type = 'weekend' THEN mean END) AS weekend_flow,
    ROUND(
        (MAX(CASE WHEN pattern_type = 'workday' THEN mean END) -
         MAX(CASE WHEN pattern_type = 'weekend' THEN mean END)) /
        NULLIF(MAX(CASE WHEN pattern_type = 'weekend' THEN mean END), 0) * 100,
        2
    ) AS pct_change,
    MAX(CASE WHEN pattern_type = 'workday' THEN truck_ratio END) AS workday_truck_ratio,
    MAX(CASE WHEN pattern_type = 'weekend' THEN truck_ratio END) AS weekend_truck_ratio
FROM baseline.baseflow_pattern_gantry
WHERE gantry_id IN ('G000551001000110010', 'G000551002000110010')
GROUP BY gantry_id, hour
ORDER BY gantry_id, hour;
```

**用途**: 周末管控策略参数设置

### 2.2 查询OD对的路径距离（SUMO精确计算）

```sql
SELECT
    o.origin_id,
    o.destination_id,
    o.mean AS od_flow,
    o.avg_travel_time,
    d.sumo_distance_km AS path_distance,
    d.distance_source,
    ROUND(d.sumo_distance_km / (o.avg_travel_time / 3600.0), 2) AS implied_speed_kmh,
    d.sumo_edge_count AS path_edge_count

  AND o.hour = 8
  AND d.distance_source = 'sumo'  -- 仅SUMO精确距离
ORDER BY o.mean DESC
LIMIT 50;
```

### 3.2 对比所有收费站的进出口流量差（识别失衡点）

```sql
SELECT
    t_on.square_code,
    t_on.hour,
    t_on.mean AS entry_flow,
    t_off.mean AS exit_flow,
    (t_on.mean - t_off.mean) AS flow_diff,
    ROUND(
        (t_on.mean - t_off.mean) / NULLIF(t_on.mean, 0) * 100,
        2
    ) AS imbalance_pct
FROM baseline.baseflow_pattern_tollsquare_on t_on
JOIN baseline.baseflow_pattern_tollsquare_off t_off
  ON t_on.square_code = t_off.square_code
  AND t_on.pattern_type = t_off.pattern_type
  AND t_on.hour = t_off.hour
  AND t_on.batch_id = t_off.batch_id
WHERE t_on.pattern_type = 'workday'
  AND t_on.hour = 8
ORDER BY ABS(t_on.mean - t_off.mean) DESC;
```

**用途**: 识别流量不平衡的收费站（可能存在数据问题或特殊交通模式）

### 5.3 计算仿真结果的偏离σ（显著性检验）

```sql
-- 假设仿真结果存储在临时表 sim_results(gantry_id, simulated_speed)
SELECT
    h.entity_id AS gantry_id,
    s.simulated_speed,
    h.speed_baseline_mean,
    h.speed_baseline_std,
    -- 计算偏离σ
    ROUND(
        (s.simulated_speed - h.speed_baseline_mean) / NULLIF(h.speed_baseline_std, 0),
        2
    ) AS deviation_sigma,
    -- 显著性判定
    CASE
        WHEN ABS((s.simulated_speed - h.speed_baseline_mean) / NULLIF(h.speed_baseline_std, 0)) > 2
        THEN '效果显著'
        ELSE '效果不显著'
    END AS significance,
    h.speed_upper_threshold,
    h.speed_lower_threshold
FROM highway.historical_baseline h
JOIN sim_results s ON h.entity_id = s.gantry_id
WHERE h.dimension = 'gantry'
  AND h.pattern_type = 'workday';
```

**用途**: 统计学显著性检验

### 8.3 计算GEH指标（流量匹配度）

```sql
-- 假设仿真结果存储在 sim_results(gantry_id, time_5min, sim_flow)
SELECT
    d.start_gantryid AS gantry_id,
    d.start_time,
    d.total AS observed_flow,
    s.sim_flow AS simulated_flow,
    -- GEH指标
    ROUND(
        SQRT(
            2 * POWER(s.sim_flow - d.total, 2) /
            NULLIF(s.sim_flow + d.total, 0)
        ),
        2
    ) AS geh,
    -- GEH验收标准
    CASE
        WHEN SQRT(2 * POWER(s.sim_flow - d.total, 2) / NULLIF(s.sim_flow + d.total, 0)) < 5
        THEN '合格'
        ELSE '不合格'
    END AS geh_status
FROM dwd.dwd_flow_gantry_weekly d
JOIN sim_results s
  ON d.start_gantryid = s.gantry_id
  AND d.start_time = s.time_5min
WHERE d.start_time BETWEEN '2025-09-22 07:00:00' AND '2025-09-22 09:00:00'
ORDER BY geh DESC;
```

**用途**: 流量校准精度评估

### 8.4 计算MAPE（平均绝对百分比误差）

```sql
SELECT
    d.start_gantryid AS gantry_id,
    COUNT(*) AS sample_count,
    ROUND(
        AVG(
            ABS(s.sim_flow - d.total)::NUMERIC / NULLIF(d.total, 0)
        ) * 100,
        2
    ) AS mape_pct,
    CASE
        WHEN AVG(ABS(s.sim_flow - d.total)::NUMERIC / NULLIF(d.total, 0)) * 100 < 15
        THEN '优秀'
        WHEN AVG(ABS(s.sim_flow - d.total)::NUMERIC / NULLIF(d.total, 0)) * 100 < 25
        THEN '良好'
        ELSE '待改进'
    END AS accuracy_level
FROM dwd.dwd_flow_gantry_weekly d
JOIN sim_results s
  ON d.start_gantryid = s.gantry_id
  AND d.start_time = s.time_5min
```

### 10.3 对比管控前后的KPI变化（模拟结果）

```sql
-- 假设管控后仿真结果存储在 sim_kpi_results(gantry_id, sim_speed, sim_congestion_hours)
SELECT
    h.entity_id AS gantry_id,
    -- 管控前（历史基线）
    h.speed_baseline_mean AS before_speed,
    k.congestion_hours AS before_congestion_hours,
    -- 管控后（仿真结果）
    s.sim_speed AS after_speed,
    s.sim_congestion_hours AS after_congestion_hours,
    -- 变化量
    s.sim_speed - h.speed_baseline_mean AS speed_change,
    s.sim_congestion_hours - k.congestion_hours AS congestion_change,
    -- 变化率
    ROUND((s.sim_speed - h.speed_baseline_mean) / NULLIF(h.speed_baseline_mean, 0) * 100, 2) AS speed_change_pct,
    -- 显著性
    ROUND((s.sim_speed - h.speed_baseline_mean) / NULLIF(h.speed_baseline_std, 0), 2) AS deviation_sigma,
    CASE
        WHEN ABS((s.sim_speed - h.speed_baseline_mean) / NULLIF(h.speed_baseline_std, 0)) > 2
        THEN '效果显著'
        ELSE '效果不显著'
    END AS significance
FROM highway.historical_baseline h
JOIN highway.batch_kpi_summary k
  ON h.entity_id = k.entity_id
  AND h.pattern_type = k.pattern_type
JOIN sim_kpi_results s
  ON h.entity_id = s.gantry_id
WHERE h.dimension = 'gantry'
  AND h.pattern_type = 'workday'
  AND k.batch_id = '20250922_20250928'
ORDER BY speed_change DESC;
```

**用途**: 管控效果评估与显著性检验

### 10.4 生成仿真验证报告（综合精度指标）

```sql
-- 假设仿真结果存储在 sim_results(gantry_id, time_5min, sim_flow, sim_speed)
WITH validation_metrics AS (
    SELECT
        d.start_gantryid AS gantry_id,
        COUNT(*) AS sample_count,
        -- GEH指标
        AVG(
            SQRT(
                2 * POWER(s.sim_flow - d.total, 2) /
                NULLIF(s.sim_flow + d.total, 0)
            )
        ) AS avg_geh,
        SUM(CASE
            WHEN SQRT(2 * POWER(s.sim_flow - d.total, 2) / NULLIF(s.sim_flow + d.total, 0)) < 5
            THEN 1 ELSE 0
        END)::NUMERIC / COUNT(*) * 100 AS geh_pass_rate,
        -- MAPE指标（流量）
        AVG(ABS(s.sim_flow - d.total)::NUMERIC / NULLIF(d.total, 0)) * 100 AS flow_mape,
        -- MAPE指标（速度）
        AVG(ABS(s.sim_speed - d.avg_speed)::NUMERIC / NULLIF(d.avg_speed, 0)) * 100 AS speed_mape
    FROM dwd.dwd_flow_gantry_weekly d
    JOIN sim_results s
      ON d.start_gantryid = s.gantry_id
      AND d.start_time = s.time_5min
    WHERE d.start_time BETWEEN '2025-09-22 07:00:00' AND '2025-09-22 09:00:00'
    GROUP BY d.start_gantryid
)
SELECT
    gantry_id,
    sample_count,
    ROUND(avg_geh, 2) AS avg_geh,
    ROUND(geh_pass_rate, 2) AS geh_pass_rate_pct,
    ROUND(flow_mape, 2) AS flow_mape_pct,
    ROUND(speed_mape, 2) AS speed_mape_pct,
    CASE
        WHEN geh_pass_rate >= 85 AND flow_mape < 15 THEN '优秀'
        WHEN geh_pass_rate >= 70 AND flow_mape < 25 THEN '良好'
        ELSE '待改进'
    END AS accuracy_level
FROM validation_metrics
ORDER BY accuracy_level, geh_pass_rate DESC;
```

**用途**: 自动生成验证报告

## 附录：常用函数与计算公式

### A1. GEH指标（流量匹配度）

```sql
GEH = SQRT(2 * (仿真流量 - 观测流量)^2 / (仿真流量 + 观测流量))

验收标准：
- GEH < 5：合格
- 85%样本点 GEH < 5：仿真整体合格
```

### A2. MAPE（平均绝对百分比误差）

```sql
MAPE = AVG(|仿真值 - 观测值| / 观测值) × 100%

验收标准：
- MAPE < 15%：优秀
- MAPE < 25%：良好
- MAPE >= 25%：待改进
```

### A3. 偏离标准差倍数（显著性检验）

```sql
偏离σ = (仿真KPI - 基线均值) / 基线标准差

显著性判定：
- |偏离σ| > 2：效果显著（95%置信度）
- |偏离σ| > 3：效果极显著（99.7%置信度）
```

### A4. 容量估算（HCM简化公式）

```sql
估算容量 = P85流量 / 0.85
或
估算容量 = 车道数 × 2000 veh/h （理论容量）
```

### A5. 流量单位换算

```sql
veh/5min × 12 = veh/hour
veh/hour ÷ 12 = veh/5min
```

### A6. 时间单位换算

```sql
秒 ÷ 60 = 分钟
分钟 × 60 = 秒
```
