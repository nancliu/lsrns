### Step 4: 运行第一个查询（5分钟）
```sql
-- 查询最新批次的门架流量基准（工作日）
SELECT
    gantry_id,
    hour,
    mean AS avg_flow_per_5min,
    p85,
    truck_ratio,
    avg_speed
FROM baseline.baseflow_pattern_gantry
WHERE pattern_type = 'workday'
  AND hour = 8
ORDER BY mean DESC
LIMIT 10;
```

**预期结果**: 返回10个流量最高的门架（早8点工作日）

## 🎓 附录：术语表

| 术语 | 英文 | 解释 |
|------|------|------|
| DWD层 | Data Warehouse Detail | 数据明细层（5分钟粒度真实数据） |
| Baseline层 | Baseline Aggregation Layer | 基准聚合层（24小时模式化数据） |
| Highway层 | Highway Analysis Layer | 分析评估层（KPI与批次分析） |
| KPI | Key Performance Indicator | 关键绩效指标（9个可用指标） |
| GEH | Geoffrey E. Havers | 流量匹配度指标（<5为合格） |
| MAPE | Mean Absolute Percentage Error | 平均绝对百分比误差（<15%为优秀） |
| P50/P85/P95 | Percentile 50/85/95 | 流量分位数（中位数/接近峰值/极端峰值） |
| MTT | Mean Travel Time | 平均行程时间（分钟） |
| μ±2σ | Mean ± 2×Std | 均值±2倍标准差（95%置信区间） |
| SUMO | Simulation of Urban MObility | 开源交通仿真平台 |
