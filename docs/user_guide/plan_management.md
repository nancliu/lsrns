# 方案管理用户指南

## 概述

方案管理模块允许您创建、编辑和管理交通控制方案。每个方案可以包含一个或多个控制策略(VSS、TEC、DHS等),用于不同的交通场景和优化目标。

## 核心概念

### 什么是控制方案?

**控制方案(Control Plan)** 是一组控制策略的组合,用于特定交通场景的优化。方案通过引用策略实例来组织多个策略,形成综合的管控措施。

**关键特点**:
- 一个方案可以包含0个或多个策略引用
- 策略引用可以设置优先级和启用状态
- 方案可以设置标签、目标场景等元数据
- 基准方案(Baseline Plan)不包含任何策略,作为对比基准

### 方案类型

1. **基准方案(Baseline Plan)**
   - 不包含任何控制策略
   - 用作对比基准,评估策略效果
   - 系统默认提供,不可删除

2. **单策略方案**
   - 包含单个控制策略
   - 用于评估单一策略的效果
   - 例如: 早高峰可变限速方案

3. **复合策略方案**
   - 包含多个控制策略
   - 策略间可能有协同效应
   - 例如: VSS+DHS复合管控方案

### 策略引用系统

方案不直接包含策略配置,而是**引用已存在的策略实例**:

```
Plan (方案)
  └── Strategy Reference (策略引用)
       ├── strategy_id: "strategy_real_vss_g4202_001"
       ├── is_enabled: true
       └── priority: 1
```

**优势**:
- 策略可在多个方案间复用
- 修改策略配置自动影响所有引用它的方案
- 方便策略版本管理和对比

## 使用指南

### 创建新方案

#### 步骤1: 准备策略

在创建方案前,确保所需的策略实例已经创建:

1. 进入 **策略管理** 页面
2. 查看可用的策略实例列表
3. 记录需要使用的策略ID(例如: `strategy_real_vss_g4202_001`)

#### 步骤2: 创建方案

1. 进入 **方案管理** 页面
2. 点击 **新建方案** 按钮
3. 填写方案信息:
   - **方案名称**: 唯一标识符,建议使用描述性名称
     - 格式建议: `plan_<策略类型>_<场景>_<描述>`
     - 示例: `plan_vss_morning_peak_simple`
   - **描述**: 简要说明方案用途和预期效果
   - **选择策略**: 从策略列表中勾选需要的策略
   - **标签**: 添加分类标签,方便筛选
     - 建议标签: 早高峰、晚高峰、VSS、TEC、DHS、G4202、G5等
   - **目标场景**: 说明方案适用的具体交通场景
     - 示例: "工作日早高峰(7:00-9:00)"

4. 点击 **保存方案**

#### 示例: 创建早高峰VSS方案

```
方案名称: plan_vss_morning_peak_simple
描述: G4202绕西双流段早高峰可变限速优化方案
选择策略:
  ☑ strategy_real_vss_g4202_001 (G4202绕西双流段早高峰可变限速)
标签: 早高峰, VSS, G4202, 单策略
目标场景: 工作日早高峰(7:00-9:00),G4202 K52.4拥堵点疏导
```

---

### 编辑方案

1. 在方案列表中找到需要编辑的方案
2. 点击方案卡片上的 **编辑** 按钮
3. 修改方案信息:
   - 可修改: 描述、策略引用、标签、目标场景
   - 不可修改: 方案名称(用作唯一标识)
4. 点击 **保存** 保存修改

**注意事项**:
- 修改方案不会影响已完成的批量仿真结果
- 正在运行的批量仿真会继续使用旧配置
- 基准方案不允许编辑

---

### 删除方案

1. 在方案列表中找到需要删除的方案
2. 点击方案卡片上的 **删除** 按钮
3. 确认删除操作

**限制**:
- 基准方案不允许删除
- 正在被批量仿真使用的方案不允许删除
- 删除后无法恢复,请谨慎操作

---

### 查看方案详情

点击方案卡片可查看详细信息:

- 方案元数据(名称、描述、创建时间等)
- 引用的策略列表及其配置
- 方案标签和目标场景
- 历史使用记录(在哪些批量仿真中使用)

---

### 方案筛选

使用页面顶部的筛选工具快速找到方案:

1. **搜索框**: 按方案名称搜索
2. **标签筛选**: 按标签过滤方案
3. **显示基准方案**: 切换是否显示基准方案

**示例**:
- 搜索 "vss" → 显示所有VSS相关方案
- 标签筛选 "早高峰" → 显示所有早高峰场景方案

## 最佳实践

### 1. 方案命名规范

**推荐格式**: `plan_<策略类型>_<场景>_<描述>`

| 方案类型 | 命名示例 | 说明 |
|---------|---------|------|
| 基准方案 | `baseline_plan` | 无控制策略 |
| 单策略方案 | `plan_vss_morning_peak_simple` | 早高峰VSS简单方案 |
| 复合策略方案 | `plan_vss_dhs_morning_composite` | 早高峰VSS+DHS复合方案 |
| 全天方案 | `plan_vss_dhs_tec_allday_complex` | 全天VSS+DHS+TEC复杂方案 |

### 2. 标签使用建议

**时段标签**:
- 早高峰 (7:00-9:00)
- 晚高峰 (17:00-19:00)
- 全天

**策略类型标签**:
- VSS (可变限速)
- TEC (收费站管控)
- DHS (动态硬路肩)

**路段标签**:
- G4202 (成都绕城高速)
- G5 (京昆高速)
- 特定路段编号

**复杂度标签**:
- 单策略
- 多策略
- 复合方案

### 3. 方案设计原则

1. **先简后繁**: 先创建单策略方案,验证效果后再组合
2. **对比基准**: 始终保留基准方案用于效果对比
3. **场景明确**: 清晰定义方案适用的交通场景和时段
4. **策略协同**: 复合方案中的策略应避免冲突,确保协同效应
5. **标签完整**: 添加完整标签,方便后续筛选和管理

### 4. 方案版本管理

当需要优化现有方案时:

- **不推荐**: 直接修改现有方案(会丢失历史配置)
- **推荐**: 创建新版本方案,保留旧版本用于对比
  - 例如: `plan_vss_morning_v1` → `plan_vss_morning_v2`

## 常见场景示例

### 场景1: 早高峰单一拥堵点疏导

**背景**: G4202 K52.4在早高峰(7:00-9:00)出现严重拥堵,平均速度仅15.14 km/h

**方案设计**:
```
方案名称: plan_vss_morning_peak_severe
描述: G4202 K52.4早高峰严重拥堵点VSS疏导方案
策略引用:
  - strategy_real_vss_g4202_001 (G4202 K52.4早高峰可变限速)
标签: 早高峰, VSS, G4202, 严重拥堵
目标场景: 工作日早高峰(7:00-9:00),K52.4拥堵点疏导
预期效果: 速度提升230%,从15km/h提升至50km/h
```

**背景**: G4202早高峰多点拥堵,需要VSS+DHS复合管控

```
方案名称: plan_vss_dhs_morning_composite
描述: G4202早高峰VSS+DHS复合管控方案
策略引用:
  - strategy_real_vss_g4202_001 (优先级1,已启用)
  - strategy_real_vss_g4202_002 (优先级2,已启用)
  - strategy_real_dhs_g4202_001 (优先级3,已启用)
标签: 早高峰, VSS, DHS, G4202, 复合方案

预期效果: 综合疏导拥堵,提升路网整体通行效率
```

**背景**: 需要覆盖早晚高峰和全天时段的综合管控

**方案设计**:
```
方案名称: plan_vss_dhs_tec_allday_complex
描述: 全天候VSS+DHS+TEC综合管控方案
策略引用:
  - strategy_real_vss_morning (早高峰VSS,优先级1)
  - strategy_real_vss_evening (晚高峰VSS,优先级2)
  - strategy_real_dhs_allday (全天DHS,优先级3)

标签: 全天, VSS, DHS, TEC, G4202, 复杂方案
目标场景: 全天候交通管控,覆盖早晚高峰和平峰时段
预期效果: 全天候优化,削峰填谷,提升路网整体运行效率
```

## 常见问题

### Q1: 为什么不能修改方案名称?

**A**: 方案名称用作唯一标识符,在批量仿真和历史记录中引用。修改会导致引用失效。如需更改,请创建新方案并删除旧方案。

### Q2: 修改策略配置后,引用该策略的方案会受影响吗?

**A**: 会。方案通过ID引用策略,策略配置修改后,所有引用该策略的方案在下次使用时都会应用新配置。如需保留旧配置,请创建新版本策略。

### Q3: 基准方案可以添加策略吗?

**A**: 不可以。基准方案必须为空(不包含任何策略),用作对比基准。如需添加策略,请创建新方案。

### Q4: 删除策略后,引用该策略的方案会怎样?

**A**: 系统会阻止删除被方案引用的策略。必须先删除引用该策略的方案,或修改方案移除该策略引用,才能删除策略。

### Q5: 一个方案可以包含多少个策略?

**A**: 理论上无限制,但建议控制在1-5个策略,过多策略可能导致:
- 配置复杂度增加
- 策略间冲突风险增加
- 仿真时间延长

### Q6: 如何判断方案是否有效?

**A**: 通过批量仿真对比方案与基准方案的效果:
1. 创建批次,包含基准方案和测试方案
2. 运行仿真
3. 对比结果中的改善百分比
4. 分析峰值曲线,观察流量变化

### Q7: 方案可以跨案例使用吗?

**A**: 可以。方案只引用策略ID,不绑定特定案例。但要确保:
- 策略引用的路段在目标案例的路网中存在
- 案例的交通流量模式与方案设计场景匹配

## 进阶技巧

### 1. 方案A/B测试

对比两个相似方案的微小差异:

```
Plan A: plan_vss_speed_50
  - VSS限速50 km/h

Plan B: plan_vss_speed_60
  - VSS限速60 km/h

批量仿真对比 → 确定最优限速值
```

### 2. 策略组合优化

逐步添加策略,评估增量效果:

```
Phase 1: baseline_plan (基准)
Phase 2: plan_vss_only (仅VSS) → 评估VSS效果
Phase 3: plan_vss_dhs (VSS+DHS) → 评估DHS增量效果
Phase 4: plan_vss_dhs_tec (VSS+DHS+TEC) → 评估TEC增量效果
```

### 3. 场景敏感性分析

同一策略在不同场景下的效果:

```
scenario_morning_peak: plan_vss_morning
scenario_evening_peak: plan_vss_evening
scenario_weekend: plan_vss_weekend

对比同一策略在不同案例(场景)中的表现
```
