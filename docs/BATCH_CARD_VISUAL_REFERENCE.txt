================================================================================
                            CSS 关键属性参考
================================================================================

容器属性 (.batch-card-actions):
  display: flex;
  gap: 8px;
  flex-wrap: nowrap;        ← 禁止换行！
  align-items: center;      ← 垂直居中

按钮属性 (.btn-small):
  flex: 1 1 auto;
  flex-basis: 计算值        ← 根据按钮数量调整
  min-width: 0;             ← 允许收缩小于内容宽度
  white-space: nowrap;      ← 防止文字换行
  overflow: hidden;         ← 隐藏溢出
  text-overflow: ellipsis;  ← 显示省略号

================================================================================
                        常见问题速查
================================================================================

Q: 按钮为什么有省略号？
A: 文字超过按钮宽度时自动显示。这是正常的响应式行为。

Q: 按钮可以换行吗？
A: 不，flex-wrap: nowrap 强制禁止换行。按钮宽度会自动压缩。

Q: 如何调整按钮宽度？
A: 通过 CSS 的 flex-basis 计算值调整（已自动化）。

Q: 为什么我看不到第四个按钮的宽度规则？
A: 目前最多3个按钮。如需4个，需手动添加对应的 :has() 规则。

Q: 小屏幕上按钮是否会变小？
A: 是的，在 <768px 时字体从 0.75rem 变为 0.7rem。

Q: 按钮间距是多少？
A: 8px（桌面）, 6px（移动）。在 CSS 中定义为 gap: 8px;
