✅ 架构验证 (Architecture Verification)
  ├─ ✅ 事件案例级进度 (Event Case Level Progress)
  │  └─ 公式: (已完成simulation数 / 总simulation数) × 100
  │  └─ 数据来源: 所有场景的 simulation 状态聚合
  │  └─ 显示位置: 顶部进度条、监控面板
  │
  ├─ ✅ 场景级进度 (Scenario Level Progress)
  │  └─ 公式: (该场景已完成simulation数 / 该场景总simulation数) × 100
  │  └─ 数据来源: 该场景的 simulation 完成状态计数
  │  └─ 显示位置: 详细表格的场景行
  │
  └─ ✅ Simulation级进度 (Individual Progress)
     └─ 数据来源: progress.json 的 percent 字段
     └─ 显示位置: 详细表格的 simulation 行

前端启动:
  用户点击 "启动仿真"
    ↓
  startBatch()
    ↓
  调用 API: POST /api/v1/simulation/batch_start
    ↓
  showMonitoringPanel()
    ├─ 显示监控面板
    ├─ 设置折叠/展开状态
    └─ 启动 monitoringInterval (1000ms)
    ↓
  定时刷新循环:
    ├─ refreshBatchStatus()
    │  ├─ 调用 API: GET /api/v1/simulation/simulation_progress/{case_id}
    │  ├─ 解析响应 (simulations, stats)
    │  ├─ 更新统计卡片
    │  ├─ 计算进度百分比: (stats.completed / stats.total) * 100
    │  ├─ 更新进度条
    │  └─ 调用 renderSimulationTable(simulations)
    │     ├─ 按 case_id 分组
    │     ├─ 按 scenario_id 分组
    │     ├─ 计算场景级进度
    │     └─ 渲染表格
    │
    └─ 每 1 秒重复，直到:
       ├─ 所有 simulation 完成 (自动停止)
       └─ 用户点击 "取消批次" (手动停止)
