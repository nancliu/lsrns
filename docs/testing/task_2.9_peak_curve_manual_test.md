**排查步骤**:
```bash
# 1. 检查浏览器控制台（F12）
# 查找JavaScript错误

# 2. 验证Chart.js库加载
# 控制台输入: typeof Chart
# 应返回: "function"

# 3. 检查API响应
curl "http://localhost:8000/api/v1/control/optimization/batch/BATCH_ID/results?include_time_series=true"

# 4. 验证Canvas元素存在
# 浏览器控制台: document.querySelector('canvas')
# 应返回canvas元素
```

### 问题2: 曲线数据异常

**症状**: 曲线全是0或数据点很少

**排查步骤**:
```bash
# 1. 检查summary.xml文件是否存在
ls cases/CASE_ID/simulations/plan_opti/BATCH_ID/*/sim_*/summary.xml

# 2. 检查summary.xml内容
cat cases/CASE_ID/simulations/plan_opti/BATCH_ID/baseline_plan/sim_66/summary.xml

# 3. 验证仿真是否真正执行
# summary.xml应包含多个<step>标签，不应为空

# 4. 检查仿真日志
cat cases/CASE_ID/simulations/plan_opti/BATCH_ID/baseline_plan/sim_66/simulation_metadata.json
```

### 问题3: 性能问题

**症状**: 图表加载很慢或浏览器卡顿

**排查步骤**:
```bash
# 1. 检查数据点数量
# 数据点数 = 仿真时长(秒) / step_length
# 如果>10000个点，可能需要优化

# 2. 查看API响应大小
curl -w "%{size_download}\n" "http://localhost:8000/api/v1/control/optimization/batch/BATCH_ID/results?include_time_series=true" -o /dev/null

# 3. 建议: 减少仿真时长进行测试
# 使用3600秒（1小时）而非86400秒（24小时）
```

### 问题4: 聚合统计不准确

**症状**: mean/std/min/max值看起来不对
