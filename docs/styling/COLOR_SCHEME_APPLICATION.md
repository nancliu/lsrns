## 📱 响应式设计

CSS 包含 3 个响应断点：

| 断点 | 触发条件 | 调整 |
|------|---------|------|
| 1200px | 中等屏幕 | 图表网格调整为最小 350px |
| 768px | 平板/手机 | 图表改为单列，表格字号减小 |
| - | 打印模式 | 移除阴影，优化打印显示 |

## ✨ 特点

### 1. CSS 变量系统
所有颜色都定义为 CSS 变量，便于后续维护和切换主题：

```css
:root {
    --color-page-bg: #f8fafc;
    --color-card-bg: #ffffff;
    --color-text-primary: #0f172a;
    /* ... 更多变量 */
}
```

### 2. 阴影系统
定义了三级阴影用于不同深度：

```css
--shadow-sm: 0 1px 2px rgba(0, 0, 0, 0.05);    /* 浅层 */
--shadow-md: 0 2px 8px rgba(0, 0, 0, 0.08);    /* 中层 */
--shadow-lg: 0 4px 16px rgba(0, 0, 0, 0.1);    /* 深层 */
```

### 3. 边框半径一致
所有圆角使用 `border-radius: 6px` 或 `8px`，保持视觉一致性

### 4. 间距规范
使用 `gap` 和 `padding` 的一致值，保持排版规范

## 📝 后续维护

### 如何修改颜色
1. 打开 `batch-results-theme.css`
2. 修改 `:root` 中的 CSS 变量
3. 所有使用该变量的地方都会自动更新

### 示例：修改主要蓝色
```css
/* 修改前 */
--color-info: #3b82f6;

/* 修改后 */
--color-info: #2563eb;  /* 更深的蓝色 */
```

### 添加新的颜色
```css
:root {
    /* ... 现有变量 */
    --color-custom: #your-color;
}

/* 在样式中使用 */
.custom-element {
    color: var(--color-custom);
}
```
