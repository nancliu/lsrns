问: EdgeData 是什么?
答: SUMO 输出的边级流量数据，包含时间间隔内每条边的进出车数、速度、密度等。

问: 为什么需要第二层分析?
答: 第一层仅分析单仿真;第二层支持多方案对标、策略评估、时空演变。

问: 28项功能用来做什么?
答:
  • A-B-C: 对比、时空、策略 → 定量评估改善效果
  • D-E: 优化、诊断 → 找出改善机会
  • F: 报告、可视化 → 展示成果

问: 需要多长时间实现?
答:
  • P0核心: 13项, 3周 (1人)
  • 加P1: 23项, 5.5周 (1人)
  • 全部: 28项, 6.5周 (1人)

问: 从哪里开始?
答:

  2. 读 COMPREHENSIVE GUIDE (30分钟) → 理解需求

                          📊 关键指标
================================================================================

【EdgeData 标准指标】

属性          单位        范围      用途
─────────────────────────────────────────────────────────────────────────
entered       辆         0-∞       进入边的车辆数
left          辆         0-∞       离开边的车辆数
speed         m/s        0-50      平均速度
traveltime    秒         0-∞       平均通过时间
density       车/km      0-150     车辆密度
occupancy     无         0-1       车道占用率
waitingTime   秒         0-∞       等待总时长
sampledSeconds 秒        0-∞       采样秒数(车·秒)

【派生指标计算】

指标              = 计算方式                    范围
─────────────────────────────────────────────────────────────────────────
流量率            = entered / (duration_hours)  0-∞
拥堵指数          = waitingTime / duration     0-1
速度比率          = speed / speed_limit        0-1
容量利用率        = flow / capacity            0-1
效率指数          = (v/v_max) × (f/f_max) × (1-CI) 0-1

【策略评估关键数字】

参考值                      目标范围
─────────────────────────────────────────────────────────────────────────
VSS速度改善                 10-30%
TEC流量改善                 10-25%
DHS容量增加                 15-30%
协调控制综合改善            25-40%
全网拥堵缓解                15-35%

【性能目标】

指标                  目标值        方法
─────────────────────────────────────────────────────────────────────────
单仿真处理时间       <30秒         向量化 + 缓存
10仿真对比时间       <5分钟        并行处理
报告生成时间         <2分钟        模板渲染
