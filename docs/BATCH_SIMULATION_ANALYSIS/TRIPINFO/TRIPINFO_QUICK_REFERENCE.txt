                     ⚡ 30秒快速了解 TripInfo
================================================================================

问: TripInfo 是什么?
答: SUMO 输出的车辆行程统计，包含每辆车的出发、到达、行程时间、延误等。

问: 为什么需要第二层分析?
答: 第一层仅记录单仿真数据；第二层支持多方案对标、策略评估、OD分析。

问: 24项功能用来做什么?
答:
  • A-B: 对比与时间分析 → 定量评估方案效果
  • C: 策略评估 → 评价控制措施效果
  • D: OD分析 → 识别主要走廊、优化优先级
  • E: 高级分析 → 行为、成本、容量分析
  • F: 报告展示 → 可视化成果

问: 与 EdgeData 有什么区别?
答:
  • EdgeData: 边级聚合数据，路网流量视角
  • TripInfo: 车级个体数据，出行体验视角
  互补使用，提供全面分析

问: 需要多长时间实现?
答:
  • P0核心: 9项, 2周 (1人)
  • 加P1: 19项, 4周 (1人)
  • 全部: 24项, 5周 (1人)

问: 从哪里开始?
答:
  1. 读本快速参考 (5分钟) → 了解全貌
  2. 读 COMPREHENSIVE GUIDE (25分钟) → 理解需求
  3. 按优先级开发 P0 功能

【TripInfo 标准属性】

属性              单位        范围      用途
────────────────────────────────────────────────────────────────────────
depart            秒         0-∞       出发时间
arrival           秒         0-∞       到达时间
duration          秒         0-∞       出行总时间
routeLength       米         0-∞       行驶距离
waitingTime       秒         0-∞       被动等待时间
waitingCount      次         0-∞       停止次数
timeLoss          秒         0-∞       因拥堵增加的时间
departDelay       秒        -∞-∞       出发延误

【派生指标计算】

指标              = 计算方式                    范围
────────────────────────────────────────────────────────────────────────
平均速度          = routeLength / duration      0-50 m/s
效率评分          = routeLength / (duration × avg_speed) 0-1
延误比例          = timeLoss / (duration - waitingTime) 0-1
停止频率          = waitingCount / (routeLength/1000) 0-∞ /km
人小时            = duration / 3600             小时

【策略评估参考值】

参考值                      目标范围
────────────────────────────────────────────────────────────────────────
出行时间改善                10-30%

排放减少(CO2)               10-20%
拥堵成本节约                20-50% (RMB/人)
通勤满意度改善              15-35 分
