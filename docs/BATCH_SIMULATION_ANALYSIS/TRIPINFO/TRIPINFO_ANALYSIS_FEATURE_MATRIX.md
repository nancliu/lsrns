| **G2-A3** | 停止频率对比 | 2+仿真 | 停止次数、等待时间 | 1.5天 | 停止次数改善 |
| **G2-B1** | 出发-到达时间分析 | 单/多仿真 | 散点图、关系分析 | 1.5天 | 时间延迟特征 |
| **G2-C1** | 出行时间改善评估 | Baseline+方案 | 改善率、达成度 | 2天 | 目标达成度 (%) |
| **G2-C2** | 延误减少评估 | Baseline+方案 | 延误改善、成本 | 1.5天 | 人小时减少 |
| **G2-D1** | 主要OD对识别 | TripInfo+TAZ | OD矩阵、排序 | 1.5天 | 主要OD对数量 |
| **G2-F1** | 综合报告 | 所有分析 | HTML报告 | 2天 | 报告完整度 |
| **G2-F4** | 交互仪表板 | 多仿真 | 交互式网页 | 3天 | 实时性、交互性 |
