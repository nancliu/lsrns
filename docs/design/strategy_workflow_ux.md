# 策略管理工作流 UX 设计

**版本**: v1.0
**创建日期**: 2025-10-21
**更新内容**: 用户体验优化，模板信息可见性改进

## 1. 工作流程概述

### 1.1 三步骤流程

```
步骤1: 选择模板
    ↓
步骤2: 选择路段（带模板信息提示）
    ↓
步骤3: 配置参数
```

### 1.2 设计原则

1. **模板优先策略** - 先选择策略类型，再选择适用路段
2. **智能引导** - 根据模板类型提供筛选建议
3. **信息透明** - 步骤2显示已选模板信息，避免用户困惑
4. **灵活返回** - 允许随时返回上一步修改选择

---

## 2. 步骤1：选择模板

### 2.1 界面元素

- **模板卡片**：展示策略类型、名称、描述
- **策略徽章**：VSS（可变限速）、DHS（动态硬路肩）、TEC（收费站管控）
- **选中状态**：视觉高亮选中的模板

### 2.2 用户操作

1. 浏览可用模板
2. 点击选择模板
3. 自动进入步骤2

---

## 3. 步骤2：选择路段（重点优化）

### 3.1 已选模板信息卡片（新增功能）

**显示位置**：步骤2顶部，筛选面板之前

**卡片内容**：
```
┌─────────────────────────────────────────────────┐
│ 已选模板：VSS基础模板 [可变限速]    [更换模板] │
│                                                 │
│ 💡 筛选建议：可变限速通常应用于主路路段，     │
│    建议筛选：车道数≥3、路段长度500-2000米      │
└─────────────────────────────────────────────────┘
```

**UI规范**：
- 背景色：`#ebf5fb`（浅蓝色）
- 左边框：`4px solid #3498db`（蓝色强调）
- 内边距：`15px`
- 圆角：`4px`

**交互功能**：
- "更换模板"按钮 → 返回步骤1
- 保持模板信息始终可见

### 3.2 智能筛选建议

根据策略类型自动显示相应的筛选建议：

| 策略类型 | 智能建议 |
|----------|----------|
| **VSS** | 💡 可变限速通常应用于主路路段，建议筛选：车道数≥3、路段长度500-2000米 |
| **DHS** | 💡 动态硬路肩需要宽路段，建议筛选：车道数≥4、主路类型路段 |
| **TEC** | 💡 收费站管控针对入口匝道，建议筛选：节点类型=入口、临近收费站 |

### 3.3 动态方向筛选（新增功能）

**功能描述**：根据所选路线自动显示可用的方向选项

**实现逻辑**：
```javascript
// 选择G5时 → 只显示：上行、下行
// 选择G4202时 → 显示：上行、顺时针、逆时针
// 选择SA2时 → 显示：下行、顺时针、逆时针
// 未选择路线 → 显示所有4个选项
```

**路线方向映射**：
- **环形高速** (G4202, SA2)：包含顺时针/逆时针
- **普通高速** (G5, G76, S4等)：仅包含上行/下行
- **混合型** (G4202, SA2)：同时包含上行/下行和顺时针/逆时针

### 3.4 路段筛选器

**筛选维度**（11个）：
1. 路线代码（多选下拉）
2. 路段代码（多选下拉，根据路线动态加载）
3. 最小/最大桩号（数值输入）
4. 最小/最大长度（数值输入）
5. 最小车道数（数值输入，DHS提示≥4）
6. 行驶方向（单选下拉，动态选项）
7. 节点类型（多选下拉，7种类型）
8. 示范段（多选下拉）
9. 包含门架（布尔选择）

**筛选器布局**（优化后）：
```
第一行：路线代码 | 路段代码（2列）
第二行：最小桩号 | 最大桩号 | 最小长度 | 最大长度（4列）
第三行：最小车道 | 行驶方向 | 节点类型 | 示范段（4列）
第四行：包含门架（内联）
```

## 5. 业务规则

### 5.1 DHS车道数阈值

**规则**：DHS（动态硬路肩）策略要求车道数 ≥ 4

**实现位置**：
- 前端提示：`templates.html:604` - "DHS≥4"
- 文档说明：`edge_selector_database_design.md:584` - `min_lanes=4`
- 快速指南：`quickstart.md:159` - "min_lanes=4"

### 5.2 行驶方向分类

**规则**：行驶方向根据路线类型自动区分

**方向类型**：
- `upstream` - 上行（桩号减少）
- `downstream` - 下行（桩号增加）
- `clockwise` - 顺时针（仅环形高速）
- `counterclockwise` - 逆时针（仅环形高速）

**路线分类**：
```
环形高速：G4202（成都绕城）、SA2（第二绕城）
普通高速：G5、G76、S4、G4215、G5013、S81
```

**实际数据**：
- G4202: clockwise, counterclockwise, upstream（混合型）
- SA2: clockwise, counterclockwise, downstream（混合型）
- G5: upstream, downstream（纯线性）
- 其他: upstream, downstream（纯线性）

### 5.3 节点类型

**支持的节点类型**（7种）：
1. `normal` - 普通路段
2. `diverging` - 分流
3. `merging` - 汇流
4. `lane_increase` - 车道增加
5. `lane_decrease` - 车道减少
6. `entrance` - 入口（TEC策略关键）
7. `exit` - 出口

## 7. 工作流程问答

### 7.1 为什么采用"模板→路段→参数"的顺序？

**原因**：
1. **智能引导**：根据策略类型自动提示合适的筛选条件
2. **减少错误**：避免用户为DHS策略选择2车道路段
3. **符合专业逻辑**：策略工程师通常先确定策略类型，再选择应用路段
4. **降低学习成本**：筛选建议帮助新用户快速上手

### 7.2 是否支持"路段→模板"的流程？

**当前状态**：不支持，保持单一流程避免混淆

**替代方案**：
- 在步骤2可随时点击"更换模板"返回步骤1
- 步骤指示器清晰显示当前进度
- 上一步/下一步按钮支持流程控制

**未来扩展**（如有需求）：
- 选项A：首页添加"快速选择路段"入口
- 选项B：允许跳过步骤1，在步骤3选择模板

### 7.3 为什么方向选项是动态的？

**原因**：
1. **避免无效选择**：普通高速没有顺时针/逆时针方向
2. **提升用户体验**：只显示有意义的选项
3. **反映真实数据**：环形高速和普通高速的方向表示不同

**实现**：
- 监听路线选择change事件
- 查询该路线的实际方向数据
- 动态更新方向下拉框选项
