🔍 技术亮点

1. CSS 定位策略:
   - Static 定位 (顶部): 普通文档流，自然流动，不浮动
   - Fixed 定位 (底部): 始终在屏幕底部，不受滚动影响

2. Z-index 分层:
   - z-index: auto (顶部) - 普通文档流，无特殊层级
   - z-index: 999 (底部) - 最高层级，确保始终可见

3. 响应式设计:
   - @media (max-width: 768px): 小屏幕自动隐藏底部标签栏
   - 自动调整内容 padding 防止被遮挡

4. CSS 变量使用:
   - margin-left: var(--size-sidebar-width) - 自动适应 sidebar 宽度
   - var(--spacing-*) - 使用设计系统变量

✨ 使用方法

【桌面版 (> 768px)】
- 顶部标签栏: sticky，始终在视野范围
- 底部标签栏: fixed，始终在屏幕底部
- 两个标签栏功能完全相同，按需切换

【平板/手机 (< 768px)】
- 顶部标签栏: sticky，用于导航
- 底部标签栏: 自动隐藏，节省空间

【工作流程】
1. 进入页面 -> 顶部标签默认显示"配置"
2. 配置参数 -> 创建批次
3. 点击底部"批次监控" -> 查看进度
4. 仿真完成 -> 点击"结果" -> 查看分析
