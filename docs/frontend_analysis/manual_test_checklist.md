# Task 9.3: 手动检查清单 - 策略创建全面验证

**完成日期**: 2025-11-01
**测试类型**: 手动检查 (视觉、响应式、浏览器兼容性)
**状态**: 验收清单

---

## 📋 检查清单概述

本清单用于补充 Playwright 自动化测试的不足，主要验证视觉设计、响应式布局和浏览器兼容性。

### 检查类别

1. **视觉设计验证** (颜色、间距、字体、对齐)
2. **响应式布局检查** (桌面、平板、移动)
3. **浏览器兼容性** (Chrome、Edge、Firefox)
4. **性能感受** (UI 响应速度、动画流畅度)
5. **可访问性** (键盘导航、屏幕阅读器)

---

## 1️⃣ 视觉设计验证

### 1.1 颜色和对比度

- [ ] **参数表单的背景色**
  - [ ] 背景色与文本对比度足够 (WCAG AA 标准)
  - [ ] 错误提示为红色 (#FF4444 或类似)
  - [ ] 成功状态显示为绿色 (可选)

- [ ] **时间轴可视化**
  - [ ] VSS 速度步骤的颜色分布清晰
  - [ ] DHS 时段的开放/关闭状态颜色区分明显
  - [ ] TEC 时段的颜色与策略语义相符

- [ ] **输入框边框**
  - [ ] 正常状态: 灰色边框
  - [ ] 焦点状态: 蓝色边框
  - [ ] 错误状态: 红色边框

### 1.2 间距和布局对齐

- [ ] **参数表单间距**
  - [ ] 所有 `.form-group` 之间间距一致 (margin-bottom 相同)
  - [ ] 输入框和标签之间间距合理 (不拥挤)
  - [ ] 时间轴与表格之间有适当间距 (≥15px)

- [ ] **表格列宽**
  - [ ] 所有表格列宽度均匀，没有偏差
  - [ ] 时间列宽度足够显示 "开始时间 (小时)"
  - [ ] 操作列宽度足够显示删除按钮

- [ ] **按钮对齐**
  - [ ] "添加行" 按钮与表格左对齐
  - [ ] "删除" 按钮在表格操作列中右对齐
  - [ ] 策略名称/描述旁的按钮在同一水平线上

### 1.3 字体和排版

- [ ] **标签和文本**
  - [ ] 所有标签使用相同字体大小 (14px)
  - [ ] 必填字段的 * 显示明显 (红色、粗体)
  - [ ] 提示文本的字体大小和颜色合适 (12px, 灰色)

- [ ] **表格内文本**
  - [ ] 表格列标签清晰易读
  - [ ] 表格数据对齐方式一致 (右对齐数值、左对齐文本)

## 2️⃣ 响应式布局检查

### 2.1 桌面版 (1920x1080)

- [ ] **整体布局**
  - [ ] 所有内容在一屏内展示，无需横向滚动
  - [ ] 参数表单宽度合理 (不会太窄或太宽)
  - [ ] 路段信息表和参数表都能正常显示

- [ ] **表格显示**
  - [ ] VSS 表格所有列可见 (时间、速度、操作)
  - [ ] DHS 表格所有列可见 (开始时间、结束时间、操作)
  - [ ] 时间轴完整显示，不被截断

### 2.2 平板版 (768x1024)

- [ ] **布局调整**
  - [ ] 参数输入框宽度缩小但仍可使用
  - [ ] 表格没有横向滚动条 (或可接受)
  - [ ] 按钮大小仍然可点击 (≥44px)

- [ ] **按钮布局**
  - [ ] "建议名称" 和 "重新生成描述" 按钮堆叠显示 (无需并排)
  - [ ] 操作按钮保持可用性

### 2.3 移动版 (375x667)

- [ ] **文本可读性**
  - [ ] 标签和输入框字体大小足够阅读
  - [ ] 提示文本仍然可见

- [ ] **交互元素**
  - [ ] 按钮大小足够触摸操作 (≥44px)
  - [ ] 删除按钮确认对话框可点击

- [ ] **表格显示**
  - [ ] 表格要么响应式重排，要么可水平滚动
  - [ ] 时间轴显示合理 (缩小或简化)

## 4️⃣ 性能感受

### 4.1 UI 响应速度

- [ ] **表单交互**
  - [ ] 输入文本时没有延迟或卡顿
  - [ ] 失焦验证 (blur event) 响应迅速 (<100ms)
  - [ ] 错误提示显示立即反应

- [ ] **表格操作**
  - [ ] "添加行" 按钮点击后立即添加行 (<300ms)
  - [ ] "删除行" 点击后立即消失
  - [ ] 时间轴更新流畅，无延迟

- [ ] **选择和切换**
  - [ ] 下拉框选项加载快速 (<200ms)
  - [ ] 模板切换无明显延迟
  - [ ] 路段查询在 2 秒内完成

### 4.2 动画和视觉效果

- [ ] **过渡效果**
  - [ ] 错误信息出现和消失有平滑过渡 (如有设计)
  - [ ] 时间轴更新流畅，没有闪烁
  - [ ] 表格行添加没有突兀的弹出

- [ ] **整体流畅度**
  - [ ] 滚动页面流畅，无卡顿
  - [ ] 没有明显的重排或重绘导致的闪烁

---

## 5️⃣ 可访问性检查

### 5.1 键盘导航

- [ ] **Tab 导航顺序**
  - [ ] 按 Tab 键可以遍历所有交互元素
  - [ ] 导航顺序逻辑合理 (从上到下，从左到右)
  - [ ] 不会陷入无限循环

- [ ] **快捷键支持**
  - [ ] Enter 键可以触发按钮
  - [ ] Escape 键可以关闭对话框（如适用）
  - [ ] Tab + Shift 可以反向导航

- [ ] **焦点显示**
  - [ ] 当前焦点元素有清晰的焦点指示器 (outline 或 border)
  - [ ] 焦点指示器颜色对比度足够

### 5.2 屏幕阅读器兼容性 (可选，如有条件)

- [ ] **标签关联**
  - [ ] 每个输入框都有关联的 `<label>`
  - [ ] 屏幕阅读器可以读出标签内容

- [ ] **ARIA 属性**
  - [ ] 必填字段有 `required` 或 `aria-required="true"`
  - [ ] 错误提示有 `role="alert"` (使其立即被读出)

- [ ] **语义 HTML**
  - [ ] 使用 `<button>` 而非 `<div>` 作为按钮
  - [ ] 表单使用 `<form>` 和 `<fieldset>`
  - [ ] 表格使用 `<table>` 和 `<thead>`、`<tbody>`

---

## 📊 策略类型特定检查

### VSS (时刻表示)

- [ ] **列标签正确性**
  - [ ] 列标签显示为 "时间(小时)" 而非 "开始时间"
  - [ ] 第二列标签为 "限速(km/h)"

- [ ] **时间轴语义**
  - [ ] 时间轴描述包含 "例如 7 表示从 7:00 开始" 等文字
  - [ ] 时间轴显示的是速度变化曲线（段状或梯形）

- [ ] **默认值**
  - [ ] 表格中已预填示例数据 (如有默认值)
  - [ ] 删除按钮在预填行的末尾可见

### TEC (时段表示)

- [ ] **列标签正确性**
  - [ ] 列标签显示为 "开始时间(小时)" 和 "结束时间(小时)"
  - [ ] 两列都存在

- [ ] **时间轴语义**
  - [ ] 时间轴描述包含 "7-9 表示 7:00-9:00" 等文字
  - [ ] 时间轴显示的是时段分布（彩色块）

- [ ] **车型配置**
  - [ ] 车型配置显示在表格外的独立区域
  - [ ] 不在时间区间表中重复配置

### DHS (时段表示)

- [ ] **列标签正确性**
  - [ ] 列标签显示为 "开始时间(小时)" 和 "结束时间(小时)"
  - [ ] 是否有第三列（DHS 状态或空）

- [ ] **时间轴语义**
  - [ ] 时间轴描述包含 "硬路肩开放" 等关键词
  - [ ] 时间轴清楚地显示硬路肩的开放时段

- [ ] **车道数验证**
  - [ ] 如果要求 ≥4 车道，UI 中应有提示或验证
  - [ ] 路段选择时是否有车道数过滤

- [ ] **连续性**
  - [ ] 选定的路段是否连续（如有连续性要求）
  - [ ] 路段不连续时是否有警告信息
