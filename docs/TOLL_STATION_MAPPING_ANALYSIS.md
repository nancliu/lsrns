## 1. Existing Toll Station Mapping Infrastructure

### 1.1 Database Tables (PostgreSQL dim schema)

**dim.point_toll_84** (Toll Station Points)
- Master table: ~37 stations across all demonstration routes
- Fields: station_name, station_code, route_code, tgm_stake, lng_84, lat_84, demonstration_id
- Coordinates in WGS84

**dim.point_toll_square** (Entrance/Exit Plazas)  
- Entrance/exit plazas for each toll station
- Fields: square_code, square_name, station_code_js, direction (entrance/exit/bidir), square_stake
- Directly references toll stations

**dim.taz_demonstration_mapping** (TAZ to Toll Mapping)
- Maps TAZ IDs to toll_square entries
- Links TAZ → toll entrance edges
- Generated by: shared/utilities/taz_tools/build_taz_mappings.py

**dim.gantry_demonstration_mapping**
- Maps gantry detectors to demonstration routes
- Links monitoring points to toll locations

### 1.2 TAZ Files (SUMO Network Definition)

**templates/taz_files/TAZ_6.add.xml** (Primary, validated 2025-08-25)
- 12,000+ TAZ definitions
- Toll station structure:
```xml
<taz id="G00055100500301010" name="shuangliunanzhanczadao toll(entrance)">
    <tazSource id="-1232" weight="1.00"/>  <!-- Main entrance edge -->
    <tazSink id="-1232" weight="0.00"/>    <!-- Exit edge -->
</taz>
```

## 2. Control Strategy Implementation

### 2.1 TEC Templates

**Location**: templates/control_strategies/toll_entrance_control/
- tec_flow_metering.json - Ramp metering (primary)
- tec_emergency_closure.json - Emergency entrance closure
- tec_vehicle_restriction.json - Vehicle type restrictions

Template structure (v2.0):
- entrance_edges: edge_array type
- flow_intervals: Time-based metering config
- position: Calibrator position on edge

### 2.2 Active G5 Strategies

**Files**: control_data/strategies/strategy_real_tec_g5_*.json

Strategy instance example:
```json
{
  "strategy_id": "strategy_real_tec_g5_001",
  "strategy_name": "G5成雅双流南站入口流量控制",
  "entrance_edges": ["-1232"],
  "data_source": {
    "gantry_id": "G000551005000220010",
    "taz_id": "G00055100500301010",
    "stake": "K1820.15"
  }
}
```

Mapping chain: Control Strategy → Entrance Edge → TAZ → Toll Station

## 5. What's Missing (Gaps Analysis)

### Gap 1: Automated Toll Station Discovery API

**Current**: Manual toll station configuration
**Missing**: API endpoints to:
- List toll stations by route
- Get entrance edges for a station
- Check for existing configurations
- Auto-validate edge IDs

### Gap 2: Toll Station Metadata Enrichment

**Current**: Static database records
**Missing**: Real-time data
- Queue length monitoring
- Current capacity/occupancy
- Entrance ramp saturation
- Dynamic throughput measurements

### Gap 3: Toll-Event Correlation Database

**Current**: Events CSV with managed_toll_stations field (manual references)
**Missing**: Structured table to track:
- Which strategies were active during which events
- Control effectiveness per event
- Historical correlation patterns

### Gap 4: G4202 & Other Routes

**Current**: G5 fully documented (3 entrance strategies)
**Missing**: 
- G4202 (绕城高速): Priority entrance edges identified but not verified
- G76 (厦蓉高速): Database records only
- S81 (德会高速): Database records only

### Gap 5: Toll Station Service Layer

**Current**: Logic scattered across files
**Missing**: Unified service with:
- Toll station registry & discovery
- TAZ ↔ Toll metadata linking
- Edge ID validation & mapping
- Batch operations for new routes
