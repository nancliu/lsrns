## 1. 系统概述

### 1.1 设计目标

精度分析系统旨在通过对比门架观测数据与E1检测器仿真数据，评估交通仿真的精度表现，为仿真模型校准和优化提供数据支撑。

### 1.2 核心功能

- **数据对齐**: 将门架数据与E1检测器数据按时间和空间维度对齐
- **精度评估**: 计算多种精度指标（MAPE、GEH、相关系数等）
- **可视化分析**: 生成多种图表展示精度分析结果
- **结果导出**: 提供CSV和PNG格式的分析结果

### 1.3 技术架构

```
┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│   数据输入层     │    │   分析处理层     │    │   结果输出层     │
├─────────────────┤    ├─────────────────┤    ├─────────────────┤
│ • 门架数据      │───▶│ • 数据对齐      │───▶│ • CSV文件      │
│ • E1检测器数据  │    │ • 精度计算      │    │ • PNG图表      │
│ • 仿真配置      │    │ • 指标统计      │    │ • HTML报告     │
└─────────────────┘    └─────────────────┘    └─────────────────┘
```

### 4.2 精度指标计算

#### 4.2.1 MAPE计算
```python
def calculate_mape(simulated, observed):
    # 处理分母为0的情况
    if mape_zero_policy == "filter":
        mask = observed != 0
        mape = np.mean(np.abs((simulated[mask] - observed[mask]) / observed[mask])) * 100
    elif mape_zero_policy == "epsilon":
        observed_eps = observed.replace(0, epsilon)
        mape = np.mean(np.abs((simulated - observed_eps) / observed_eps)) * 100
    return mape
```

#### 4.2.2 GEH指标计算
```python
def compute_geh(simulated, observed):
    den = (simulated + observed) / 2.0
    mask = den != 0
    geh = np.sqrt(((simulated[mask] - observed[mask]) ** 2) / den[mask])
    return geh
```

## 5. 数据质量标准

### 5.1 输入数据要求

#### 5.1.1 门架数据标准
- **必需字段**: gantry_id, start_time, flow, speed
- **时间格式**: ISO 8601标准格式
- **数值范围**: flow ≥ 0, speed > 0
- **数据完整性**: 缺失率 < 20%

#### 5.1.2 E1检测器数据标准
- **必需字段**: detector_id, begin, end, flow, speed, occupancy
- **时间格式**: 秒级时间戳
- **数据来源**: SUMO仿真输出XML文件
- **解析要求**: 支持多文件批量处理
- **字段说明**: 
  - `flow`: 仿真输出的交通流量（辆/时间区间）- **优先使用**
  - `volume`: 进入车辆数（辆/时间区间）- **备用字段**
  - **兼容性处理**: 如果XML中缺少flow字段，系统会自动使用volume字段作为flow的替代
  - **精度分析**: 统一使用flow字段进行精度计算

### 5.2 输出数据标准

#### 5.2.1 CSV文件标准
- **编码格式**: UTF-8 with BOM
- **分隔符**: 逗号
- **数值精度**: 浮点数保留4位小数
- **缺失值**: 使用空字符串表示

#### 5.2.2 PNG图表标准
- **分辨率**: 300 DPI
- **尺寸**: 标准尺寸（8x6, 10x8, 12x8英寸）
- **色彩**: 支持中文字符显示
- **格式**: 24位真彩色PNG

```python
def handle_missing_values(data, strategy='drop'):
    if strategy == 'drop':
        return data.dropna()
    elif strategy == 'interpolate':
        return data.interpolate(method='linear')
    elif strategy == 'fill_zero':
        return data.fillna(0)
```

#### 7.1.2 异常值检测
```python
def detect_outliers(data, method='iqr'):
    if method == 'iqr':
        Q1 = data.quantile(0.25)
        Q3 = data.quantile(0.75)
        IQR = Q3 - Q1
        lower_bound = Q1 - 1.5 * IQR
        upper_bound = Q3 + 1.5 * IQR
        return (data < lower_bound) | (data > upper_bound)
```

```python
from functools import wraps

def performance_monitor(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        start_time = time.time()
        result = func(*args, **kwargs)
        end_time = time.time()
        duration = end_time - start_time
```
