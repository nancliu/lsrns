## ✅ 正确的操作流程 (基于PRD v2.0)

根据PRD文档,管控优化子系统的核心流程应该是:

### Phase 1 MVP核心流程 (当前应实现的)

```
1. 策略配置 (CSV导入)
   ↓
2. 批次提交与并行仿真
   ↓
3. 实时监控 (状态/进度/峰值)
   ↓
4. 结果分析与Top3推荐
```

### 详细操作步骤

#### 步骤1: 策略配置 (strategy_config.html)
**目标**: 为批次中的多个并行任务配置不同的策略参数

**操作**:
1. 用户选择基础案例(case_id)
2. 上传CSV文件或填写策略参数
3. 系统验证参数有效性
4. 生成批次配置文件

**输入**: CSV文件 (格式见Epic 2.5完成报告)
```csv
instance_id,control_type,control_id,edges,params
0,VSL,vsl_1,"edge1,edge2","{""speed"":60,""begin"":25200,""end"":32400}"
1,DHS,dhs_1,"edge3,edge4","{""begin"":25200,""end"":32400}"
2,baseline,none,"","{}"
```

**输出**: batch_id + 配置文件目录

#### 步骤2: 批次提交 (同页面或新页面)
**目标**: 一键启动所有并行仿真任务

**操作**:
1. 显示批次配置摘要(实例数、策略类型分布)
2. 用户确认并提交批次
3. 系统启动并行仿真(≤60实例)

**输出**: 跳转到监控页面

#### 步骤3: 实时监控 (monitoring.html)
**目标**: 监控所有并行任务的执行状态和进度

**操作**:
1. 显示批次整体进度(完成/运行/失败数量)
2. 显示每个任务的状态和实时比
3. 30秒自动刷新状态
4. 显示峰值车辆数曲线

**关键指标**:
- 任务状态: queued/running/completed/failed
- 实时比 (realtime_ratio)
- 峰值车辆数 (peak_vehicles)
- 仿真进度 (progress%)

#### 步骤4: 结果分析 (results.html)
**目标**: 展示批次结果和Top3推荐

**操作**:
1. 加载批次指标数据
2. 显示所有任务的评分和排名
3. 高亮显示Top3推荐
4. 支持导出结果(JSON/CSV)

**关键内容**:
- 评分排名表(所有任务)
- Top3推荐卡片(金银铜标识)
- 指标对比图表(柱状图+雷达图)
- Top3与基准对比表

## 📝 附录: 用户操作手册 (简版)

### 如何运行一个管控优化批次?

#### 步骤1: 准备CSV配置文件
下载示例CSV模板,填写策略参数:
- instance_id: 实例编号 (0, 1, 2, ...)
- control_type: 策略类型 (VSL, DHS, baseline)
- edges: 管控边列表
- params: 策略参数(JSON格式)

#### 步骤2: 启动批次
1. 访问 `http://localhost:8000/control_optimization/`
2. 点击"启动批次"
3. 选择基础案例
4. 上传CSV文件
5. 确认并提交

#### 步骤3: 监控进度
1. 自动跳转到监控页面
2. 查看实时进度和状态
3. 等待所有任务完成

#### 步骤4: 查看结果
1. 点击"查看结果"
2. 查看Top3推荐
3. 下载结果报告
