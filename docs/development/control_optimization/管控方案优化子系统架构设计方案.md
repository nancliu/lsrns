## 一、架构设计概述

### 1.1 设计目标

基于最新PRD（MVP聚焦：策略参数配置→并行仿真→指标评分→Top3推荐），本架构为管控方案优化子系统提供技术实现蓝图，确保与现有OD数据处理与仿真系统无缝集成。设计目标如下：

**Phase 1 MVP目标** (Week 1-3, 12-15天):
- ✅ **需求对齐**: 聚焦PRD中Phase 1标注的核心功能
- ✅ **极简UI**: 3个页面(启动/监控/结果),30秒轮询刷新
- ✅ **模块化设计**: 遵循现有三层架构,最小化代码量
- ✅ **并行仿真**: 支持≤60实例固定调度,基础状态机
- ✅ **批次管理**: batch级edges.add.xml生成(K=2规则)
- ✅ **评分与Top3**: 固定权重评分,并列处理,稳定排序
- ✅ **文件+数据库**: 明细CSV文件,汇总入库

**Phase 2扩展目标** (Week 4+):
- 🔵 **完整监控**: WebSocket实时推送,多维度曲线
- 🔵 **错误处理**: 重试/断路器/优雅降级机制
- 🔵 **UI增强**: 策略配置表单,动态图表交互
- 🔵 **测试集成**: Playwright MCP自动化测试

### 1.2 设计原则

- **架构一致性**: 遵循现有FastAPI + PostgreSQL架构模式。
- **模块化原则**: 按业务领域组织代码模块。
- **依赖方向**: 上层依赖下层，避免循环依赖。
- **独立部署**: 支持独立的前端部署。
- **数据隔离**: 按照[PRD 4.4](./prd/4-非功能需求.md)的要求，使用独立的数据库schema隔离管控优化数据。

### 1.3 技术选型

- **后端框架**: FastAPI 0.104.1 (与现有系统一致)
- **数据库**: PostgreSQL 15+ (与现有系统一致)
- **前端技术**: HTML5 + CSS3 + JavaScript ES6+ + Material Design (对齐[FR3.1](./prd/2-功能需求.md))
- **并行处理**: 基于现有架构扩展，支持60个并行实例 (对齐[NFR1](./prd/4-非功能需求.md))
- **数据可视化**: Chart.js 4.x (对齐[FR3.2](./prd/2-功能需求.md))
- **状态管理**: 基于现有BaseService模式
- **测试框架**: Playwright MCP (Microsoft Edge浏览器) (对齐[PRD第8节](./prd/8-风险评估.md))
- **仿真引擎**: SUMO 1.18+ (与现有系统一致)

**前端错误处理机制**:
```javascript
// frontend/control_optimization/assets/js/error-handler.js
class ErrorHandler {
    constructor() {
        this.errorLog = [];
        this.maxRetries = 3;
        this.retryDelay = 1000; // 1秒
    }
    
    async handleApiError(error, context) {
        console.error(`API Error in ${context.component}:`, error);
        
        // 记录错误
        this.logError(error, context);
        
        // 根据错误类型采取不同处理策略
        if (error.status === 500) {
            return this.handleServerError(error, context);
        } else if (error.status === 429) {
            return this.handleRateLimitError(error, context);
        } else if (error.status >= 400 && error.status < 500) {
            return this.handleClientError(error, context);
        } else {
            return this.handleNetworkError(error, context);
        }
    }
    
    async handleServerError(error, context) {
        // 服务器错误 - 显示用户友好的错误信息
        this.showErrorMessage('服务器暂时不可用，请稍后重试');
        
        // 自动重试
        return this.retryOperation(context.operation, context.params);
    }
    
    async handleRateLimitError(error, context) {
        // 速率限制错误 - 等待后重试
        this.showErrorMessage('请求过于频繁，请稍后重试');
        
        await this.delay(this.retryDelay * 2);
        return this.retryOperation(context.operation, context.params);
    }
    
    async handleClientError(error, context) {
        // 客户端错误 - 显示具体错误信息
        const errorMessage = error.response?.data?.message || '请求参数错误';
        this.showErrorMessage(errorMessage);
        
        return null; // 不重试客户端错误
    }
    
    async handleNetworkError(error, context) {
        // 网络错误 - 检查网络连接并重试
        if (!navigator.onLine) {
            this.showErrorMessage('网络连接已断开，请检查网络设置');
            return null;
        }
        
        this.showErrorMessage('网络连接异常，正在重试...');
        return this.retryOperation(context.operation, context.params);
    }
    
    async retryOperation(operation, params) {
        for (let attempt = 1; attempt <= this.maxRetries; attempt++) {
            try {
                await this.delay(this.retryDelay * attempt);
                return await operation(...params);
            } catch (error) {
                if (attempt === this.maxRetries) {
                    throw error;
                }
                console.log(`Retry attempt ${attempt} failed:`, error);
            }
        }
    }
    
    showErrorMessage(message) {
        // 显示用户友好的错误信息
        const errorContainer = document.getElementById('error-container');
        if (errorContainer) {
            errorContainer.innerHTML = `
                <div class="error-message">
                    <i class="material-icons">error</i>
                    <span>${message}</span>
                </div>
            `;
            errorContainer.style.display = 'block';
            
            // 3秒后自动隐藏
            setTimeout(() => {
                errorContainer.style.display = 'none';
            }, 3000);
        }
    }
    
    logError(error, context) {
        this.errorLog.push({
            timestamp: new Date().toISOString(),
            error: error.message,
            context: context,
            stack: error.stack
        });
        
        // 发送错误日志到服务器
        this.sendErrorLog(error, context);
    }
    
    async sendErrorLog(error, context) {
        try {
            await fetch('/api/v1/control_optimization/log_error', {
                method: 'POST',
                headers: {
                    'Content-Type': 'application/json',
                },
                body: JSON.stringify({
                    error: error.message,
                    context: context,
                    timestamp: new Date().toISOString(),
                    userAgent: navigator.userAgent,
                    url: window.location.href
                })
            });
        } catch (logError) {
            console.error('Failed to send error log:', logError);
        }
    }
    
    delay(ms) {
        return new Promise(resolve => setTimeout(resolve, ms));
    }
}

// 全局错误处理器实例
const errorHandler = new ErrorHandler();

// 全局错误处理

    errorHandler.handleApiError(event.error, {
        component: 'Global',
        operation: 'Unknown'
    });
});

// 未处理的Promise拒绝
window.addEventListener('unhandledrejection', (event) => {
    errorHandler.handleApiError(event.reason, {
        component: 'Global',
        operation: 'Promise'
    });
});

class CircuitBreaker:
    def __init__(self, config: CircuitBreakerConfig):
        self.config = config
        self.failure_count = 0
        self.last_failure_time = None
        self.state = "CLOSED"  # CLOSED, OPEN, HALF_OPEN
    
    async def call(self, func: Callable, *args, **kwargs):
        if self.state == "OPEN":
            if self._should_attempt_reset():
                self.state = "HALF_OPEN"
            else:
                raise Exception("Circuit breaker is OPEN")
        
        try {
            result = await func(*args, **kwargs)
            self._on_success()
            return result
        except self.config.expected_exception as e:
            self._on_failure()
            raise e
    
    def _should_attempt_reset(self) -> bool:
        return (datetime.now() - self.last_failure_time).seconds >= self.config.recovery_timeout
    
    def _on_success(self):
        self.failure_count = 0
        self.state = "CLOSED"
    
    def _on_failure(self):
        self.failure_count += 1
        self.last_failure_time = datetime.now()
        
        if self.failure_count >= self.config.failure_threshold:
            self.state = "OPEN"

# shared/utilities/graceful_degradation.py
class GracefulDegradationManager:
    def __init__(self):
        self.degradation_levels = {
            'full': 100,      # 完整功能
            'limited': 80,     # 限制功能
            'minimal': 50,     # 最小功能
            'offline': 0       # 离线模式
        }
        self.current_level = 'full'
    
    async def check_system_health(self):
        """检查系统健康状态"""
        health_checks = {
            'database': await self._check_database_health(),
            'simulation_engine': await self._check_simulation_health(),
            'api_services': await self._check_api_health()
        }
        
        # 根据健康检查结果确定降级级别
        failed_services = sum(1 for health in health_checks.values() if not health)
        
        if failed_services == 0:
            self.current_level = 'full'
        elif failed_services <= 1:
            self.current_level = 'limited'
        elif failed_services <= 2:
            self.current_level = 'minimal'
        else:
            self.current_level = 'offline'
        
        return self.current_level
    
    async def _check_database_health(self):
        """检查数据库健康状态"""
        try {
            # 简单的数据库连接测试

            conn.close()
            return True
        except Exception:
            return False

        """检查仿真引擎健康状态"""
        try {
            # 检查SUMO进程是否可用
            import subprocess
            result = subprocess.run(['sumo', '--version'], 
                                  capture_output=True, timeout=5)
            return result.returncode == 0
        except Exception:
            return False
    
    async def _check_api_health(self):
        """检查API服务健康状态"""
        try {
            # 检查关键API端点
            import httpx
            async with httpx.AsyncClient() as client:
                response = await client.get('/api/v1/health', timeout=5)
                return response.status_code == 200
        except Exception:
            return False
    
    def get_available_features(self):
        """根据当前降级级别返回可用功能"""
        features = {
            'full': [
                'case_creation', 'strategy_configuration', 'simulation_execution',

            ],

            'emergency_scenario': self._validate_emergency_strategy
        }
    
    def validate_strategies(self, strategies):
        """验证策略配置"""
        validated_strategies = []
        for strategy in strategies:
            strategy_type = strategy.get('strategy_type')
            if strategy_type not in self.supported_strategies:
                raise ValueError(f"不支持的策略类型: {strategy_type}")
            
            validated_params = self.supported_strategies[strategy_type](
                strategy.get('parameters', {})
            )
            
            validated_strategy = {
                'strategy_type': strategy_type,
                'parameters': validated_params,
                'instance_count': strategy.get('instance_count', 1)
            }
            validated_strategies.append(validated_strategy)
        
        return validated_strategies
    
    def _validate_vsl_strategy(self, params):
        """验证可变限速策略参数"""
        required_params = ['speed_limit', 'detection_interval']
        for param in required_params:
            if param not in params:
                raise ValueError(f"VSL策略缺少必需参数: {param}")
        
        if params['speed_limit'] < 30 or params['speed_limit'] > 120:
            raise ValueError("限速值应在30-120km/h范围内")
        
        return params
```

class PeakDetector:
    """峰值检测器 - 负责检测交通流峰值"""
    
    def __init__(self, threshold=1000000, window_size=50):
        self.threshold = threshold
        self.window_size = window_size
        self.peak_intervals = []
    
    def detect_peaks(self, vehicle_counts):
        """检测峰值区间"""
        peaks = []
        current_peak = None
        
        for i, count in enumerate(vehicle_counts):
            if count >= self.threshold:
                if current_peak is None:
                    current_peak = {'start': i, 'max_count': count}
                else:
                    current_peak['max_count'] = max(current_peak['max_count'], count)
            else:
                if current_peak is not None:
                    current_peak['end'] = i
                    current_peak['duration'] = i - current_peak['start']
                    peaks.append(current_peak)
                    current_peak = None
        
        return peaks
    
    def calculate_duration(self, peak_interval):
        """计算峰值持续时长"""
        return peak_interval['end'] - peak_interval['start']
