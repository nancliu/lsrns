## 🚀 快速开始

### 新开发者入门

1. **了解项目背景**:
   - 阅读 [管控方案优化子系统PRD文档.md](./planning/管控方案优化子系统PRD文档.md) - 了解目标和范围
   - 阅读 [管控方案优化子系统架构设计方案.md](./planning/管控方案优化子系统架构设计方案.md) - 理解技术架构

2. **查看当前进展**:
   - 阅读 [Epic1_完成报告.md](./reports/Epic1_完成报告.md) - 了解已完成的工作
   - 阅读 [MVP功能清单.md](./planning/MVP功能清单.md) - 了解功能实现状态

3. **开始开发**:
   - 查看 [TODO.md](./TODO.md) - 获取待办任务列表
   - 查看 [下一阶段开发建议_20251003.md](./planning/下一阶段开发建议_20251003.md) - 了解优先级
   - 选择任务并开始编码

### 测试人员入门

1. **阅读测试指南**:
   - [MVP测试指南.md](./planning/MVP测试指南.md) - 了解测试流程和验收标准

2. **运行手动测试**:
   - 参考 [tests/manual/README.md](../../../tests/manual/README.md)
   - 启动服务器并执行测试脚本

3. **查看测试结果**:
   - 检查 `cases/*/control_optimization/` 目录中的输出文件
   - 验证性能指标是否达标
