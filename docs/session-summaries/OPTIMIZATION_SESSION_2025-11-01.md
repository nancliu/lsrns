## 🔍 根本原因分析

### 为什么 3 个测试在 120s 时仍然超时?

**关键观察**:
- 所有超时都发生在正好 120 秒时
- 浏览器在此时被 Playwright 框架关闭
- Step 1-2 都成功完成
- Step 3 参数加载也成功进行

**结论**:
不是 120s 不够长，而是参数表单的 DOM 计数操作触发了某个问题导致浏览器被迫关闭。

**可能原因**:
1. 参数表单太复杂 (大量 DOM 节点)
2. 表单渲染未完全完成
3. 内存或资源耗尽
4. JavaScript 错误导致页面崩溃
