### 01_系统概述与架构设计.md
**用途**：全面理解系统架构、设计决策与技术基础
**核心章节**：
1. **项目背景与目标**
   - 定义：OD仿真决策支持系统
   - 规模：1000+km路网、720万+数据条目
   - 版本：v0.9.0

2. **两层模块化架构**
   - API层结构（7个service，6个routes）
   - Shared层结构（utilities, data_access, analysis_tools, processors）
   - 单向依赖关系

3. **架构决策记录（ADR）**
   - ADR-001: 两层模块化
   - ADR-002: FastAPI + Pydantic
   - ADR-003: 连接池优化（30倍性能）
   - ADR-004: 两步式仿真
   - ADR-005: JSON配置模板
   - ADR-006: E2E生产数据测试
   - ADR-007: 三级元数据追踪

4. **技术栈全景**
   - 后端：FastAPI、PostgreSQL、SUMO、Pandas
   - 前端：HTML5、JavaScript ES6+、Chart.js
   - 运维：Conda、pytest、Playwright、Black、flake8

5. **整体工作流**
   - 用户工作流：场景→案例→仿真→分析→结果
   - 系统内部处理流：API→服务→Shared→DB

**关键指标**：
- 代码复用度↑82%
- 维护时间↓90%
- 性能提升90%（连接池）

### 03_关键技术-计算层.md
**用途**：理解仿真执行、配置生成与多维度分析算法
**核心章节**：
1. **SUMO仿真引擎集成**
   - 配置生成工具：200+参数自动化
   - 车型配置系统：JSON驱动，运行时灵活
   - 支持两种仿真类型：microscopic/mesoscopic

2. **两步式仿真工作流（ADR-004）**
   - Phase 1 - Prepare：生成配置，保存状态pending
   - Phase 2 - Start：加载配置，启动SUMO
   - 优势：支持配置检查、参数调整、中断控制
   - 向后兼容：保留一步式API

3. **多策略耦合评估框架**
   - 支持4种策略：NO_CONTROL、VSS、TEC、DHS
   - 智能匹配：基于事件特征推荐策略
   - 并行执行：4个场景并行，性能提升4倍
   - 自动对比：聚合结果、生成报告

4. **四维度分析算法**
   - 精度分析：MAPE、GEH、相关系数、R²
   - 机理分析：速度、流量、拥堵、OD流向
   - 性能分析：模拟时间、墙钟时间、加速比、车辆数
   - EdgeData分析：路段流量、速度、密度、拥堵识别

**关键数字**：
- 99.7%效率提升（手工→自动）
- 92.1% GEH合格率
- 8.7% MAPE精度
- 4倍 并行化性能提升

**检索：** 如果你想了解SUMO配置、仿真工作流、分析算法，看这章
